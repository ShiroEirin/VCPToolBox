# VCP 文件管理与系统控制工具箱能力收纳
这里收纳了文件搜索、读写、批量操作及系统命令行工具。

## 1. PowerShell 命令行工具 (PowerShellExecutor)
直接调用并获取运行结果。支持 VCP-CLI (前端) 和紧凑的后端命令行。
tool_name:「始」PowerShellExecutor「末」, // 使用 ServerPowerShellExecutor 运行后端版本
command:「始」Get-ChildItem「末」,
executionType:「始」blocking/background「末」, // 默认blocking。background用于长时任务。
newSession:「始」true「末」, // 仅前端，代表新建窗口。
requireAdmin:「始」true「末」 // 提升权限。Server版需输入6位安全码。 // 例如tool_password:「始」123456「末」

## 2. 文件快速搜索 (LocalSearchController)
基于 Everything 模块实现秒级搜索。
tool_name:「始」LocalSearchController「末」, // ServerSearchController 代表操作服务器
command:「始」search「末」,
query:「始」搜索关键词 (支持Everything语法)「末」,
maxResults:「始」50「末」

## 3. 基础文件阅读 (FileOperator)
阅读电脑内任何区域的文件，支持富文本/多媒体。
tool_name:「始」FileOperator「末」, // ServerFileOperator 代表服务器文件
command:「始」ReadFile「末」,   
filePath:「始」/path/to/your/document.pdf「末」

## VCP 项目代码结构参考
- **后端 (VCPToolBox)**: 使用 `ServerFileOperator`
  - `server.js`, `Plugin.js`, `KnowledgeBaseManager.js`, `WebSocketServer.js`
  - `modules\chatCompletionHandler.js` (核心逻辑)
  - `Plugin\RAGDiaryPlugin` (记忆/思考)
- **前端 (VChat)**: 使用 `FileOperator`
  - `H:\MCP\VCPChat\main.js`, `renderer.js`
  - `H:\MCP\VCPChat\modules`, `Assistantmodules`

<<<[TOOL_REQUEST]>>>
tool_name:「始」FileOperator「末」,
command1:「始」RenameFile「末」,
sourcePath1:「始」/path/to/old_name.txt「末」,
destinationPath1:「始」/path/to/new_name.txt「末」
command2:「始」RenameFile「末」,
sourcePath2:「始」/path/to/old_name2.txt「末」,
destinationPath2:「始」/path/to/new_name2.txt「末」
command3:「始」EditFile「末」,
filePath3:「始」/path/to/existing_file.txt「末」,
content3:「始」这是覆盖后的新内容。「末」
<<<[END_TOOL_REQUEST]>>>

## 6. [重要] 转义文件创造 
当需要创建内部包含「始」「末」等VCP指令语法的文件时（例如生成插件的配置文件），必须使用转义写入。

即使用 「始ESCAPE」 包裹包含VCP工具指令的内容 「末ESCAPE」

[重要提示：在向用户演示指令而非真正调用工具的时候，也应该遵守转义原则！]

tool_name:「始」FileOperator「末」,
command:「始」CreateCanvas「末」,
fileName:「始」new_canvas.js「末」,
content:「始」console.log('Hello, Canvas!');「末」

## 8. 代码检索器 (CodeSearcher)
在VCP项目源码中搜索指定的代码片段或关键词。支持正则表达式。
tool_name:「始」CodeSearcher「末」, // ServerCodeSearcher 代表搜索后端代码
query:「始」(必需) 关键词或正则表达式「末」,
search_path:「始」(可选) 指定搜索的相对路径「末」,
case_sensitive:「始」(可选) true/false，默认false「末」,
whole_word:「始」(可选) true/false，默认false「末」,
context_lines:「始」(可选) 匹配行前后显示的上下文行数，默认2「末」

## 9. 插件源码查询器 (PluginSourceViewer)
查询指定 VCP 插件在本地的源码。自动扫描 Plugin 目录下启用的 plugin-manifest.json，按 manifest.name 匹配并返回主代码文件内容与目录树（忽略 node_modules/target/dist 等）。
tool_name:「始」PluginSourceViewer「末」,
command:「始」ViewPluginSource「末」,
targettool:「始」(必需) 插件工具名，必须对应 manifest.name，例如 AnySearch、DigitalOracle、AgentAssistant、ServerFileOperator「末」

## 10. 插件管理器 (PluginManager)
查询/启停 VCP 插件注册表。
tool_name:「始」PluginManager「末」,
command:「始」ListPlugins「末」, //或 GetPluginDetail / EnablePlugin / DisablePlugin / ReloadPlugins
pluginName:「始」(详情/启停时必需) 插件唯一英文名「末」,
requireAdmin:「始」(必需) 用户提供的6位管理员验证码「末」 //仅可启停 synchronous/asynchronous/static 类型插件

## 11. 工具调用记录查询 (ToolCallRecordQuery)
查询 VCP 工具调用记录，默认返回 AI 友好的 Markdown 报告，自动摘要嵌套 JSON 并把 base64 图片迁移为可访问 URL。
tool_name:「始」ToolCallRecordQuery「末」,
id:「始」(可选) 记录ID，detail 为 true 时返回单条详情「末」,
from/to:「始」(可选) 起始/结束时间（ISO 或可解析时间）「末」,
caller:「始」(可选) 调用者署名模糊查询「末」,
toolName:「始」(可选) 工具名模糊查询「末」,
success:「始」(可选) true/false「末」

## 12. AI 代码工程 Worker (AICodeWorker)
把耗 Token 的代码读写任务交给本地免费的 opencode 执行，VCP 模型只需下命令和看结果。
tool_name:「始」AICodeWorker「末」,
command:「始」run_and_wait「末」,
preset:「始」index / read / scan / bug...「末」, //内置预设：index(函数索引) read(读全文) scan(扫目录树) bug(找bug)等
targetPath:「始」(必需) 文件或目录的绝对路径「末」,
projectPath:「始」(可选) 项目路径，不填时从 targetPath 自动推导「末」

在安全沙箱中执行 Linux Shell 命令，支持本地和远程 SSH 执行。
tool_name:「始」LinuxShellExecutor「末」,
command:「始」要执行的 Shell 命令，或 preset:预设名?参数 格式「末」,
hostId:「始」(可选) 目标主机ID，默认 local「末」,
isLongRunning:「始」(可选) 是否为长待机指令「末」,
requireAdmin:「始」(可选) 管理员验证码，可授权灰名单/未知命令「末」 //分号;、后台&、子shell $() 被硬护栏禁止且不可绕过
