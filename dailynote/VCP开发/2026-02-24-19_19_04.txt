1.【BilibiliFetch 分P修复】(commit: 4f691deb)

二、VCPChat 前端变更（2/21-2/24）

1.【串行指令延迟控制】(commit: ee3f6f7c) ★重要
toolCallHandler.js 的 executeSerialCalls 重构：
- 新增 config 配置项：toolCall.serialDelay (默认500ms)、toolCall.maxRetries (默认2次)
- 串行调用间自动插入延迟，避免插件进程竞争

2.【全局电脑控制 + peripheralBridge】(commit: c8061e36) ★新特性
新增 peripheralBridge.js 外设桥接模块：
- moveMouse(x,y)：移动鼠标到指定坐标
- mouseClick(button, x, y)：鼠标左/右键点击
- sendKeys(keys)：键盘输入（基于 SendKeys API）
- captureScreen(region)：全屏或区域截图，保存为临时PNG
- getMousePosition()：获取当前鼠标坐标
- 全部基于 PowerShell + System.Windows.Forms 实现，目前仅支持 win32

- FileManager.vue 和 FileTreeView.vue 大幅重构

三、gh CLI 工作流经验
- gh auth status 确认登录状态和 token scope
- gh api repos/{owner}/{repo}/commits 获取提交列表，用 --jq 过滤
- 用完整 SHA（至少8位真实值）调用 gh api repos/.../commits/{sha} 获取详情
- PowerShell 中 jq 的单引号语法需要注意转义，复杂过滤建议用 PowerShell 原生 ConvertFrom-Json
- patch 字段可能很大，注意超时风险
