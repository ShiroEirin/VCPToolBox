一、VCP 功能矩阵总览（FEATURE_MATRIX.md）

- 同步/异步/静态三种插件调用模式
- vcp_dynamic_fold 动态语义折叠：基于余弦相似度的上下文自适应展开，静态插件输出带 threshold 的 fold_blocks，系统根据用户 query 与 plugin_description 的相似度决定展开哪一层
- 串行调用延迟+重试：默认500ms间隔、2次重试，可在 config.js 配置
- TagMemo 浪潮RAG：标签语义分组+时间衰减+多窗口检索
- Rust 向量引擎 Vexus-Lite：余弦相似度计算提升约12x
- 分布式节点通信+文件超栈追踪
- WorkspaceInjector 目录树注入+.workspaceignore 过滤
- 模型重定向 ModelRedirect.json
- VCP Auth 验证码机制
- Agent 梦境系统 AgentDream

二、Rust 向量引擎 Vexus-Lite（RUST_VECTOR_ENGINE.md）

用途：替代纯JS的向量计算，服务于RAG检索和vcp_dynamic_fold语义匹配。
API：
- cosineSimilarity(vecA, vecB) → [-1,1] 浮点数
- batchCosineSimilarity(queryVec, vectors[]) → 相似度数组
- topK(queryVec, vectors[], k) → [{index, score}]
- normalize(vec) → 归一化向量

性能（1536维向量）：
- 单次余弦相似度：0.15ms→0.012ms（12x）
- 批量1000条：150ms→9.8ms（15x）
- Top-K 10000条：920ms→58ms（16x）

跨平台预编译：Win x64 / Linux x64 GNU+MUSL / Linux ARM64 / macOS ARM64
降级策略：Rust加载失败自动回退JS实现，EmbeddingUtils.js 中 try-catch 处理

三、记忆系统（MEMORY_SYSTEM.md）

VCP记忆系统七大组件：
1. 日记系统 DailyNote：按[日记本名]Agent名分类，Tag标签，向量化入SQLite
2. TagMemo 浪潮RAG：语义组粗筛→组内精排→时间衰减加权→多窗口(7天/30天/全部)合并去重→Top-K
3. 知识库 KnowledgeBaseManager：SQLite+Vexus-Lite，增量更新，跨库检索
4. 深度回忆 DeepMemo：搜索历史聊天记录，高级语法（精确短语/加权/排除/OR）
5. 快速回忆 LightMemo：RAG语义检索日记本，支持rerank
6. vcp_dynamic_fold：静态插件语义折叠
7. EPA残差金字塔：实验性，对话历史近/中/远三层压缩

关键配置 rag_params.json：
- similarity_threshold: 0.35（相似度阈值）
- time_decay_factor: 0.95（时间衰减因子）
- semantic_group_threshold: 0.7（语义组聚合阈值）
- multi_window_weights: recent=1.0, medium=0.8, long_term=0.6
