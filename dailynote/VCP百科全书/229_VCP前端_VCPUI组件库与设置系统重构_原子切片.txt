一、概述
上游 lioensky 自 2026-08-31 起在 VCPChat 进行了为期4天的大规模 UIUX 重构（本仓库第15次合并实收 375 提交，248 文件 +36830/-10891，142 个新文件）。核心是三件事：
1. 引入自包含 VCPUI 组件库（modules/uiux/），WebAwesome Web Components 的 vendored 运行时
2. 全局设置页与 Agent 设置页的"schema 驱动渲染"彻底重构（modules/settings/）
3. 新主题系统实测 + 2 个新官方主题

二、VCPUI 组件库（modules/uiux/ + vendor/webawesome-runtime/）
- vendor/webawesome-runtime/：@awesome.me/webawesome 3.11.0 的 vendored 本地运行时（vcp-runtime-manifest.json 带 sha256 校验清单，locale zh-CN），含 button/card/input/textarea/select/option/checkbox/switch/tab/tab-panel/tab-group/dialog/tooltip 共13个组件的 dist-cdn 产物——上游为避免 CDN 依赖把组件库直接搬进仓库
- modules/uiux/：自包含 VCPUI 封装层（theme-presenter、settings-adapter、primitives、dom-renderer、service-registry 等，tests/uiux-*.test.mjs 共10个测试文件）
- npm scripts 新增：check:uiux:artifacts / check:uiux / build:uiux / test:uiux / check:settings-ownership / audit:settings-layout / guard:ui-interaction / guard:ui-async-state / guard:ui-task-journeys / guard:theme-provenance / test:settings-wa-electron

三、设置系统 schema 驱动重构（modules/settings/ 新增 23 文件）
- modules/settings/schema/：设置分区 schema 定义（kernel.js/appearance-settings.js/voice-settings.js/server-connection.js/user-identity.js/quick-actions.js/advanced-features.js/render-settings.js/selection-assistant.js）
- modules/settings/render/：canonical-row.js / field-renderer.js / widgets.js / shared.js 分层渲染器
- modules/settings/store.js + value-semantics.js + schema-surface.js：设置存储与值语义
- 配套文档：docs/global-settings-section-ownership.md、docs/research/settings-schema-render-plan.md、docs/settings-autosave-coordinator-*.md（自动保存协调器的开发计划/验收/交接三件套）
- 目标：全局设置页各分区权责清晰（check-global-settings-section-ownership.mjs 门禁脚本固化），schema 单一事实来源，渲染层薄化
