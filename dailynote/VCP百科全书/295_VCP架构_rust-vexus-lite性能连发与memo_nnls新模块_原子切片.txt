## 一、新增 memo_nnls.rs（569 行）——NNLS 求解器
源码头部事实：
```rust
use nalgebra::{DMatrix, DVector};

const DUAL_TOL: f64 = 1e-10;
const RANK_TOL: f64 = 1e-12;
const CHECK_TOL: f64 = 2e-8;

pub(crate) struct Diagnostics {
    iterations, active_tags, dual_violation, stationarity_error,
    complementarity_error, energy_closure_error, residual_ratio
}
pub(crate) struct Solution {
    projection: Vec<f32>, residual: Vec<f32>,
    // Unit-Tag coefficients divided by input query norm.
    contributions: Vec<f64>,
}
```
- **NNLS = Non-Negative Least Squares（非负最小二乘）**：强制系数非负，即「记忆只能加分不能减分」。
- **KKT 条件诊断齐备**：`dual_violation`（对偶可行）、`stationarity_error`（平稳性）、`complementarity_error`（互补松弛）——三个量正好是 KKT 三条件，说明作者把「解对不对」变成了**可量化验收**。
- **`energy_closure_error` + `residual_ratio`**：能量闭合与残差比，用于判断投影是否漏能。
- `contributions` 注释原文：`Unit-Tag coefficients divided by input query norm.`——贡献度做了归一化，可跳模型比较。
