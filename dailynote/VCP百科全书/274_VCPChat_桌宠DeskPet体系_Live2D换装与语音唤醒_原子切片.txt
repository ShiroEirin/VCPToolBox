七、风险

1. **`defaultEnabled: true`**：升级后桌宠默认开启，会立刻占资源（Live2D 渲染 + 唤醒监听）。低配机器建议先关。
2. **`postinstall` 新增 `node scripts/app-features.cjs install`**：`npm install` 时会执行，会下载 Cubism Core（`scripts/deskpet/fetch-cubism-core.cjs`）。**VCPChat 侧禁止跑 npm install 的规则因此更需要遵守**。
3. **唤醒需要模型文件**：`modelManager.js` 会下载 sherpa-onnx KWS 模型，首次启用需联网。
4. **独立进程的代价**：KWS 进程常驻，内存与句柄成本高于同进程；`provider: 'cpu'` 也意味着不占 GPU 但吃 CPU。
5. **`vcp-deskpet` 协议带 `secure: true`**：协议注册后页面可加载本地资源，属权限扩张，需确认加载内容来源可信。
