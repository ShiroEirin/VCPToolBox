## 核心结论
- 版本：1.0.0，类型：synchronous，协议：stdio，超时：180000ms
- 入口：`node AgnesGen.mjs`（Node.js）
- 调用 Sapiens AI Agnes Image 2.1 Flash 模型进行文生图（generate）和图生图（edit/compose），支持高信息密度图像、复杂构图、创意设计、营销素材和图像转换任务
- 无图片时自动文生图；提供 image/image_url/image_base64 等字段时自动进入图生图或多图参考模式

## 工作机制
PluginManager → stdio 启动 `node AgnesGen.mjs` → 解析 command（generate/edit/compose）→ 根据是否提供 image 字段自动判断文生图或图生图 → 调用 Agnes API → 返回生成图片 URL

## 使用/排障边界
- 高信息密度图像建议在 prompt 中清晰描述主体、背景环境、重要次要细节、风格光照、构图限制
- 不支持 negative_prompt 专用字段；如需规避内容，直接写入 prompt（如 "avoid blurry details, distorted hands"）
- 图生图任务需要说明哪些内容应保持不变
- 生成完毕后需以 Markdown 图片或 HTML `<img>` 标签直接展示
- 常见错误：AGNES_API_KEY 未配置、网络代理不通、公网/内网地址选择错误

## 命令与参数
| command | 说明 |
|---------|------|
| generate | 文生图，只需 prompt |
| edit | 图生图，需提供 image 字段 |
| compose | 多图参考合成，需提供多张图片 |

参数：prompt（必需）、size（可选，默认 1024x1024）、image（编辑/合成时必需）、showbase64（可选，默认 false）

## 配置参数（configSchema）
| 参数 | 类型 | 说明 |
|------|------|------|
| AGNES_API_KEY | string | (必需) Agnes/Sapiens AI API Bearer Token |
| AGNES_API_ENDPOINT | string | (可选) 默认 https://apihub.agnes-ai.com/v1/images/generations |
| AGNES_MODEL_ID | string | (可选) 默认 agnes-image-2.1-flash |
| AGNES_DEFAULT_SIZE | string | (可选) 默认 1024x1024 |
| HTTP_PROXY | string | (可选) 网络代理地址，如 http://127.0.0.1:7890 |
| USE_PUBLIC_URL | string | (可选) 是否使用公网地址返回图片URL，默认 false |
