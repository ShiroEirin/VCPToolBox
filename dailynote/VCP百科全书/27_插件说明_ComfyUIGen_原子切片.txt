一、插件身份
- name: `ComfyUIGen`
- displayName: `ComfyUI 图像生成器`
- version: `0.3.0`
- pluginType: `synchronous`
- protocol: `stdio`
- timeout: `300000`
- author: `niuniu`
- 入口: `node ComfyUIGen.js`（Node.js）
- command: `ComfyUIGenerateImage`

二、核心能力
- 通过 ComfyUI API 使用自定义工作流生成高质量图像。支持LoRA模型自动管理、质量增强词配置、多种工作流模板。
- 已深度集成到 VCP ToolBox，提供可视化配置界面（comfyui-settings.json）。
- 提供可调用命令：ComfyUIGenerateImage。

三、命令与参数
命令 `ComfyUIGenerateImage`，参数如下：
- `maid`（必需，字符串）：Agent的署名
- `prompt`（必需，字符串）：图像生成的正面提示词
- `negative_prompt`（可选，字符串）：额外的负面提示词，与用户配置的负面提示词合并
- `workflow`（可选，字符串）：工作流模板名称，默认使用用户配置的工作流。可选值：text2img_basic, text2img_advanced 等
- `width`（可选，整数）：生成图像的宽度，默认使用用户配置的值
- `height`（可选，整数）：生成图像的高度，默认使用用户配置的值

四、配置参数（configSchema）
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| COMFYUI_BASE_URL | string | http://localhost:8188 | ComfyUI服务器地址 |
| COMFYUI_API_KEY | string | (空) | ComfyUI API密钥（可选，本地部署通常不需要） |
| DEBUG_MODE | boolean | false | 是否启用调试模式，显示详细执行日志 |

五、工作流机制
- 读取 `comfyui-settings.json` 作为默认配置中心
- 读取 `workflows/*.json` 模板并做占位符替换
- 将生成后的prompt图提交到ComfyUI `/prompt` 接口执行
- 系统自动合并：用户提示词 + 用户配置的LoRA + 质量增强词
- 技术参数（模型、尺寸、采样器等）使用用户预设值，但 width、height 和 negative_prompt 可在调用时覆盖或追加

六、使用/排障边界
- 先固定一套稳定workflow再扩展参数
- 出图异常优先排查：节点连线、占位符替换、ComfyUI服务状态
- 当前为 .block 禁用态，不会被 PluginManager 加载
