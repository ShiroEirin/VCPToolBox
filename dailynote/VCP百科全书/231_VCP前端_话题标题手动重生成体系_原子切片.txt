# 一、功能定位

话题列表的手动"重新生成标题"入口：用户可对任意 Agent/群聊话题手动触发 AI 重新命名，不再受自动摘要的触发条件限制。标题生成基于最新最多两轮对话（MIN_MESSAGES_FOR_SUMMARY 窗口）。

# 二、topicTitleManager.js 新增 generateTitleForHistory（+28行）

- 导出 `generateTitleForHistory(groupHistory, globalVcpSettings)`：手动重新生成时**不受原话题名称和消息数量阈值限制**；过滤 `role==='system'` 与 `isThinking===true` 后取最近 MIN_MESSAGES_FOR_SUMMARY 条构建摘要内容，调 `generateTitleFromAI` → `cleanSummarizedTitle`。
- 无有效消息返回 null；AI 返回兜底名"AI总结话题"时视为失败返回 null（防止把占位符当标题存库）。

# 三、chatHandlers.js 新增 IPC regenerate-agent-topic-title（+84行）

- `ipcMain.handle('regenerate-agent-topic-title', (event, agentId, topicId))`：读 Agent config 定位话题 → 读 `history.json` 计算有效消息数（过滤 system/isThinking）→ 0 条则报"该话题还没有可用于生成标题的对话" → 读 settings.json 组装 globalVcpSettings（vcpUrl/vcpApiKey/userName/topicSummaryModel）→ 无 vcpUrl 报"请先在全局设置中配置 VCP 服务器 URL" → `topicTitleManager.generateTitleForHistory` → 通过 agentConfigManager.updateAgentConfig 原子改话题 name → 返回 `{success, newTitle, topics, sourceMessageCount}`。
- 引入新依赖：`const topicTitleManager = require('../../Groupmodules/topicTitleManager')`。
