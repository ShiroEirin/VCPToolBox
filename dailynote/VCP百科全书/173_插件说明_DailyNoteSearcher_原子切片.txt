## 工作机制
VCP 启动 → DailyNoteSearcher.js 作为 hybridservice 常驻 → 启动 Rust HTTP 服务监听 38765 端口 → VCP AI 或 RAGDiary 模块发起 SearchDailyNote 请求 → 通过 direct 协议调用本地 HTTP 服务（POST /search）→ Rust 侧执行文本/正则/BM25 搜索 → 返回匹配结果（含上下文行）

两种搜索模式：
- 默认文本/正则检索：支持 query 单关键词或 queries 多关键词 AND 匹配
- BM25 排序召回：mode=bm25，按文件修改时间倒序取候选，BM25 相关性排序

## 使用/排障边界
- 默认搜索根目录为 dailynote，检索冷知识库时传入 root_path=knowledge
- BM25 模式必须指定 folder（角色日记本目录），只检索该目录下的 md/txt 文件
- bm25_search_mode: body 匹配正文，tag 只匹配底部 tags/标签行
- 帧数必须满足 8n+1（如 81/121/241/441）
- 常见错误：端口冲突（38765被占用）、日记目录路径不正确、ALLOWED_EXTENSIONS 过滤了目标文件

## 命令与参数
| command | 说明 |
|---------|------|
| SearchDailyNote | 在日记本或 knowledge 冷知识库文件中搜索指定文本或关键词 |

默认文本/正则检索参数：query（必需）、queries（可选，多关键词AND）、folder（可选）、root_path（可选，默认dailynote）、allowed_extensions（可选）、ignored_folders（可选）、max_results（可选）、is_regex（可选，默认false）、case_sensitive（可选，默认false）、whole_word（可选，默认false）、context_lines（可选，默认2）

BM25 排序召回参数：mode（必需，bm25）、query（必需）、query_tokens（可选）、folder（必需）、root_path（可选）、bm25_limit（可选，默认10）、bm25_search_mode（可选，body/tag，默认body）、tag_blacklist（可选）、max_results（可选）

## 配置参数（configSchema）
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| DAILY_NOTE_SEARCHER_HOST | string | 127.0.0.1 | 常驻 HTTP 服务绑定地址，默认仅监听本机回环 |
| DAILY_NOTE_SEARCHER_PORT | integer | 38765 | 常驻 HTTP 服务固定端口 |
| DAILY_NOTE_SEARCHER_TIMEOUT | integer | 60000 | direct/HTTP 调用超时时间（毫秒） |
| DAILY_NOTE_ROOT | string | dailynote | 日记本根目录的相对路径 |
| MAX_RESULTS | integer | 200 | 单次搜索返回的最大结果数量 |
| IGNORED_FOLDERS | string | VectorStore,DebugLog | 搜索时忽略的文件夹列表，逗号分隔 |
| ALLOWED_EXTENSIONS | string | .md,.txt,.json,.html | 允许搜索的文件扩展名白名单 |
