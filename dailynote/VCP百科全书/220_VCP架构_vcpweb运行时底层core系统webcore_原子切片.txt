一、体系定位
VCP 浏览器/桌面 Agent 的统一运行时底层，ChromeBridge（MV3 扩展）与 Loom（Electron）双端共用同一套 core 代码。全部模块采用 IIFE 工厂模式包裹，支持双加载：浏览器全局变量（globalScope.VCPWebAgentProtocol 等，供 importScripts / content script 使用）与 Node require（module.exports）。入口 index.js 聚合 protocol / adapterContract / pageCore / pageRuntime / runtimeCore 五个必需模块（缺失任一即抛 "VCP Web Agent Core 缺少模块"），外加可选 chromeAdapter（缺省时 createChromeRuntime 抛 "当前构建不包含 Chrome Adapter"）；最终冻结导出 VCPWebAgentCore，提供 createPageRuntime / createRuntime / createChromeRuntime / getCapabilityCatalog 四个工厂入口。

七、运行时核心（web-agent-runtime-core.js）
- VERSION = '0.1.0'
- MODIFIER_BITS 修饰键位标记：alt=1 / ctrl=2 / control=2 / meta=4 / cmd=4 / command=4 / shift=8
- createKeyboardPlan：normalizeKeys 按 +/, 切分，键别名（esc→Escape、return→Enter、space、arrowup/down/left/right、pageup/pagedown）+ 特殊键表（Enter/Tab/Escape/Backspace/Delete/Arrow*/PageUp/PageDown/Home/End/Space 含 windowsVirtualKeyCode）+ 修饰键位，产出 {type:'keyboard-sequence', modifiers, keys}
- createMousePlan：click→move/down/up 序列；hover→move；scroll→wheel（amount 默认 600，direction 上下左右分页）
- buildResponseBodyResult：maxBodyChars 默认 16384（范围 0~1000000）、metadataOnly、base64Encoded、bodyBytes/bodyChars、sha256Text（crypto.subtle SHA-256 十六进制摘要）、truncated/omittedChars
- estimateBodyBytes：非 base64 用 TextEncoder 计字节，base64 按 3/4 换算
- createWebAgentRuntime(adapter, options)：构造 WebAgentRuntime（validateAdapter 校验、audit 监听、initialize 拉取能力集）
- normalizeLegacyChromeCommand：兼容旧 ChromeBridge 命令（resolveCommand + createRequest，metadata 携带 sourceClientId / chromeBridgeProtocolVersion / originalCommand），配套 formatLegacyChromeResult
- execute(input) 主入口：createRequest → validateRequest → initialize → assertCommandSupported → getTargetIdentity → getDocumentState → assertIdentity → route 按 command/domain 分派（page_* 走 executePageOperation，debugger/dom/network/emulation/storage 走 sendDebugger 的 CDP 映射，native_* 走 dispatchNativeInput，target_* 走 target 方法族）

八、适配器
- chrome-adapter.js：VERSION='0.1.0'；createChromeWebAgentAdapter(chromeApi, options) → ChromeWebAgentAdapter（id='chrome'、backend='chrome-extension'）；CAPABILITIES 12 项（page/script/debugger/runtime/dom/accessibility/nativeInput/network/storage/emulation/screenshot/targets）；chromeCall 将 MV3 回调 API 包装为 Promise 并检查 chrome.runtime.lastError；面向 MV3 扩展 background：chrome.debugger（attach/detach/sendCommand/onEvent/onDetach）、chrome.tabs（query/get/update/create/remove/reload/captureVisibleTab/onUpdated/sendMessage）、chrome.scripting.executeScript（MAIN/ISOLATED 世界）；executePageOperation 将 page_* 经 tabs.sendMessage 分派给 content script（无响应时返回 ACTION_DISPATCHED 异步）
