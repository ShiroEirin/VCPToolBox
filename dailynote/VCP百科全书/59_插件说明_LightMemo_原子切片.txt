[VCP百科全书] 插件说明——LightMemo（原子切片）

一、插件身份
- name: LightMemo
- displayName: 快速回忆 / 语义测绘 / TagMemo 实验
- version: 1.0.0
- pluginType: hybridservice
- protocol: direct
- entryPoint: LightMemo.js

二、核心能力
一个允许AI主动搜索其RAG知识库（日记、知识库）的插件，作为DeepMemo（上下文搜索）的补充。当前版本提供三个命令：

1. SearchRAG — 轻量级RAG检索
- 在日记知识库中进行向量搜索，同时支持检索TDB冷知识库（百科/手册/私有资料等大规模低频数据）。
- 核心参数：
  - `query`（必需，字符串）：查询内容。支持在query中嵌入时间范围约束语法（如 `[2025-04-11~2025-05-12]` 或 `[2026-02-14]`）。支持 `[知识库:库名]` 语法检索TDB冷知识库，支持 `[音乐检索]` 搜索MusicDiary文件夹。
  - `maid`（可选，字符串）：AI署名，支持 `[文件夹]署名` 作用域语法，方括号内可填写多个文件夹
  - `folder`（可选，字符串）：指定搜索的日记文件夹名称，支持逗号或 `|` 分隔多个文件夹
  - `k`（可选，数字，默认5）：返回结果数量
  - `rerank`（可选，默认false）：Rerank精排。可选值：false, true, `"rrf"`, `"rrf0.7"`, 或直接传入0~1之间的数字
  - `aimemo`（可选，默认false）：启用后先执行完整LightMemo检索，再将候选交给RAGDiaryPlugin共享的AIMemoHandler进行AI总结
  - `aimemo_preset`（可选，字符串）：显式指定RAGDiaryPlugin的AIMemo预设
  - `BM25` / `bm25` / `use_bm25`（可选，默认true）：是否启用BM25关键词初筛与BM25-向量混合打分
  - `search_all_knowledge_bases`（可选，默认false）：是否搜索所有知识库
  - `tag_boost`（可选，默认0.5）：TagMemo V9.1增强因子（0~1）。设置为0则禁用。在数字后加 `+` 后缀可启用V9.1查询级势能场重排（如 `"0.6+"`）
  - `core_tags`（可选，字符串数组）：核心标签列表，TagMemo优先聚焦这些标签进行增强
  - `core_boost_factor`（可选，数字，默认1.33）：核心标签的额外加权因子
  - `knowledge_base`（可选，字符串）：指定一个或多个TDB冷知识库名称，用逗号分隔

2. MapDistance — 语义测绘（新增）
- 开发测绘指令：比较一个起点A到一个或多个目标B/C/D在原始KNN与TagMemo V9.1拓扑空间中的距离差异，返回Markdown表格。
- 核心参数：
  - `command`（必需）：固定传入 `map_distance`（兼容 `MapDistance`、`mapping`、`tagmemo_map` 等）
  - `start` / `origin` / `a`（必需，字符串）：起点A文本
  - `targets` / `target` / `b`（必需，字符串或数组）：一个或多个目标文本
  - `tag_boost`（可选，默认0.6）：两端V9.1 TagMemo增强权重
  - `alpha` / `geo_alpha`（可选）：V9.1势能场加权距离中的Tag能量场权重
  - `core_tags`（可选）：核心标签列表
  - `core_boost_factor`（可选，默认1.33）：核心标签额外加权因子

3. TagMemoAB — TagMemo V9.1单轨对照测试（新增）
- TagMemo V9.1单轨记忆寻址对照测试，固定比较原始KNN、请求开始时捕获的不可变V9.1 ArtifactBundle，以及可选的独立Rerank。
- 核心参数：
  - `command`（必需）：固定传入 `tagmemo_ab`（兼容 `tagmemo_compare`、`v91_compare`）
  - `ab_mode`（可选，默认A）：A=固定对称候选超集对照，B=端到端Top-K对照
  - `query`（必需）：记忆寻址输入
  - `maid` / `folder` / `search_all_knowledge_bases`：搜索作用域
  - `k`（可选，默认5）：模式B每条路径的返回数量
  - `top_l` / `topL`（可选）：模式A每条召回路径进入对称超集的候选数
  - `tag_boost`（可选，默认0.6）：V9.1 TagMemo增强强度
  - `potential_field` / `use_potential_field`（可选，默认true）：是否执行Potential Field重排
  - `BM25` / `bm25` / `use_bm25`（可选，默认true）：模式A是否将BM25 Top-L纳入候选超集
  - `compare_rerank` / `compareRerank`（可选，默认false）：是否增加独立Rerank横向基线

三、占位符与注入点
- systemPromptPlaceholders: 无

四、配置参数（configSchema）
- `EXCLUDED_FOLDERS`（字符串）：需要屏蔽的日记文件夹名称，用逗号分隔（默认：`已整理,夜伽,MusicDiary`）
- `RerankUrl`（字符串）：Rerank服务的URL
- `RerankApi`（字符串）：Rerank服务的API密钥
- `RerankModel`（字符串）：Rerank使用的模型

五、排障建议
- 插件无响应：先检查 manifest 启用状态、入口脚本、运行时依赖
- 结果异常：核对命令名与参数字段，再查看插件目录缓存/日志文件
- BM25关闭后全候选向量精排，结果可能与默认模式有较大差异
- 冷知识库检索中 `tag_boost` / `maid` / `folder` 等参数无效，会被忽略
