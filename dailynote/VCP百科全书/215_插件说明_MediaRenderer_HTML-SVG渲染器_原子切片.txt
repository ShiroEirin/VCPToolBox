四、三条生成路径

路径A：RenderImage — 静态图片渲染（v1.1.0已有，v2.2.0增强）
- HTML/SVG → PNG、JPG、WebP
- 宽高 64-4096 像素，最大总像素 4096x4096
- PNG/WebP 透明背景，JPG 自定义底色
- 最多 16 步串行批量渲染
- v2.2.0新增：源码中直接写 file:///、HTTP/HTTPS URL 引用图片/视频/字体
- v2.2.0新增：Anime.js/Three.js CDN标签自动重定向到本地版本
- v2.2.0新增：readyMode (load/auto/signal)
- 安全限制：单资源50MB，合计100MB，每步24资源，源码2MB

路径B：RenderAnimation — 确定性逐帧动画（v2.2.0全新）
- HTML/SVG 逐帧截图 → FFmpeg 编码为 GIF/MP4/WebM
- 确定性逻辑时间：durationMs=5000, fps=30 → 150张PNG帧，每帧调用页面帧函数
- 页面协议：window.__MEDIA_RENDERER__.setFrameRenderer((timeMs, frameIndex, fps) => {...})
- 资源初始化后调用 window.__MEDIA_RENDERER__.setReady()，设置 readyMode=signal
- 视频参数：format(gif/mp4/webm), durationMs(100-60000), fps(1-60)
- 透明：GIF/WebM 支持，MP4/H.264 不支持
- audioUrl：MP4/WebM 可选音轨（data:/file:///HTTP/HTTPS）
- 编码：MP4=H.264 yuv420p, WebM=VP9, 透明WebM=yuva420p
- 运行前提：需 FFmpeg

路径C：GenerateAudio — 程序音乐合成（v2.2.0全新）
- 在独立 Node.js 子进程中执行 AI 编写的 JavaScript 合成代码
- 不启动浏览器，不需要 FFmpeg 或额外 npm 依赖
- 输出 WAV/PCM16
- 强制管理员验证码：每次调用必须提供 requireAdmin（6位验证码）

代码协议：
- 必须声明 function synthesize(api) 或 const synthesize = api => ...
- 可以是 async 函数
- 直接写入 api.left、api.right 或 api.channelData[channel] 的 Float32Array
- 采样值 -1 到 1，超出时插件归一化

内置合成 API：
| API | 说明 |
|-----|------|
| api.sampleRate | 采样率 |
| api.duration / api.durationMs | 时长（秒/毫秒） |
| api.channels | 声道数 (1或2) |
| api.tempo | BPM |
| api.seed | 随机种子 |
| api.left / api.right / api.channelData | 预分配 Float32Array 声道数组 |
| api.noteToFrequency('C#5') | 音符转 Hz |
| api.oscillator(type, phase, duty) | 波形：sine/square/pulse/triangle/saw |
| api.envelope(time, duration, options) | ADSR 包络 |
| api.addNote({note,start,duration,wave,duty,volume,pan,attack,decay,sustain,release}) | 便捷叠加音符 |
| api.random() / api.noise() | seed 控制的确定性随机/白噪声 |
| api.secondsPerBeat / api.beatToSeconds(beats) | 节拍换算 |
| api.Math | 标准数学对象 |

GenerateAudio 参数：
| 参数 | 说明 |
|------|------|
| code | 必需，合成代码，最大1MB |

六、安全限制
- 除源码明确引用并通过校验的资源外，页面运行时网络请求全部阻断
- HTTP 重定向逐跳校验，云元数据地址始终禁止
- 单资源最大 50MB，所有资源合计最大 100MB
- 每步最多 24 个资源，源码最大 2MB
- 最多串行 16 步
- Anime.js/Three.js 只识别 jsDelivr、unpkg、cdnjs 上符合路径规则的标签
- 其他远程脚本禁止执行
- GenerateAudio 需管理员验证码，子进程超时后终止进程树

AudioSynthesisWorker.js 核心函数：
- noteToFrequency(note) — 音符(如'C#5')转Hz，基于A4=440Hz
- oscillator(type, phase, duty) — sine/square/pulse/triangle/saw 波形生成
- envelope(time, duration, options) — ADSR包络（attack/decay/sustain/release）
- createRandom(seed) — 确定性PRNG

八、运行前提
- 图片渲染：VCP_BROWSER_RUNTIME_ENABLED=true + Chrome/Chromium/Edge
- 动画渲染：上述 + FFmpeg（或 FfmpegPath 指定）
- 音乐合成：仅需 Node.js（不要求浏览器或 FFmpeg）
- 插件复用根项目的 Puppeteer、Sharp 和 mime-types
