一、插件基本信息
1. 插件名称：MediaRenderer / HTML/SVG 媒体渲染器
2. 插件类型：hybridservice
3. 版本号：1.1.0
4. 通信协议：direct, timeout=300000ms (5分钟)
5. 入口文件：MediaRenderer.js
6. 功能一句话总结：使用 VCP 托管 Chrome 的 CDP 运行时，将 AI 编写的 HTML 或 SVG 渲染为 64-4096 像素的 PNG、JPG 或 WebP 图片

二、功能定位
MediaRenderer 直接调用根层浏览器运行时（browserRuntimeManager.js），取得 DevTools WebSocket Endpoint 后创建独立浏览器上下文进行渲染。不通过 ChromeBridge 传输源码或截图。

当前版本支持：
- HTML → PNG、JPG、WebP
- SVG → PNG、JPG、WebP
- 宽高各 64-4096 像素
- 最大总像素 4096x4096
- PNG/WebP 透明背景
- JPG 自定义底色
- 最多 16 步串行批量渲染
- 使用现有图片作为底图添加 CSS/SVG/Canvas 特效
- 支持 Data URI、HTTP/HTTPS 和 file:// 底图
- ImageFileServer 图床 URL 输出
- 可选 Base64 多模态返回
- 除显式底图外的外部资源请求阻断
- HTML JavaScript 默认关闭

暂不包含 GIF 和 MP4，但渲染器的输出目录及部署环境可在后续接入全局 FFmpeg 编码器。

三、配置参数
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| DebugMode | boolean | false | 是否输出 MediaRenderer 的逐步渲染诊断日志 |

运行前提：根配置必须启用 `VCP_BROWSER_RUNTIME_ENABLED=true`，服务器需具备 Chrome/Chromium/Edge。
可选指定 `VCP_BROWSER_EXECUTABLE_PATH` 为浏览器可执行文件路径。
插件复用根项目已安装的 Puppeteer 和 Sharp，不需要在插件目录单独安装依赖。

四、调用命令列表

1. RenderImage - HTML/SVG 渲染为图片
   功能描述：将完整 HTML 源码或 SVG 源码渲染为图片，适合绘制图标、Logo、信息图、卡片和壁纸，也可以基于已有图片用 HTML/CSS/SVG 添加滤镜、遮罩、文字、边框、渐变和光效。服务器直接通过 CDP 连接已有 VCP 托管 Chrome，不经过 ChromeBridge。

   参数列表：
   - command (可选)：固定为 RenderImage；省略时也按 RenderImage 执行
   - html (与 svg 二选一)：完整 HTML 文档或 HTML 片段，支持 HTML/CSS/内联 SVG
   - svg (与 html 二选一)：完整 SVG 源码
   - sourceImage (可选，兼容 image/image_url/source_image)：需要用代码编辑或添加特效的底图，支持 data:image Data URI、http/https 图片 URL 和 file:// 图片。提供后 html/svg 源码中必须使用 {{SOURCE_IMAGE}} 作为图片地址
   - width (必需)：输出宽度，整数，64-4096
   - height (必需)：输出高度，整数，64-4096
   - format (可选)：png、jpg 或 webp，默认根据 transparent 自动选择。transparent=true 且 format=jpg 时自动改为 png
   - transparent (可选)：是否保留透明背景，默认 false
   - background (可选)：非透明输出的底色，默认 #ffffff
   - quality (可选)：JPG/WebP 质量，1-100，默认 90
   - showBase64 (可选)：是否额外内联图片 Data URI，默认 false
   - allowJavaScript (可选)：是否允许 HTML 中的 JavaScript，默认 false
   - waitMs (可选)：截图前额外等待 0-10000 毫秒，默认 0
   - timeoutMs (可选)：单步超时 1000-120000 毫秒，默认 45000
   - fileName (可选)：输出文件名主体，插件会清理危险字符并自动追加唯一尾缀及扩展名

   串行批量语法：用 command1/html1/width1/sourceImage1 等数字后缀描述第 1 步，command2/svg2/width2/sourceImage2 等描述第 2 步，依次连续编号，最多 16 步。未带后缀的 format、quality、transparent、background、sourceImage、showBase64、allowJavaScript、waitMs、timeoutMs 等参数作为所有步骤的公共默认值；某一步带后缀参数会覆盖公共值。每一步按顺序渲染，最终一次返回所有图片 URL。

   安全限制：
   - 除显式 sourceImage 外，其他 HTTP/HTTPS、file: 等资源请求全部阻断
   - 只允许源码内联资源、data: 和 blob:
   - sourceImage 本地或内联图片最大 25MB
   - HTML/SVG 源码最大 2MB
   - 单次最多 16 张

依赖模块：
- `puppeteer` — CDP 浏览器控制
- `sharp` — 图片后处理
- `browserRuntimeManager.js` — VCP 托管浏览器运行时管理（根层模块）

七、关联插件
- ChromeBridge (24)：Chrome 桥接插件，MediaRenderer 不通过 ChromeBridge，直接使用根层 CDP
- ImageFileServer：提供图床 URL 输出
- GPTImageGen / ZImageTurboGen / VideoGenerator：其他图像/视频生成插件
