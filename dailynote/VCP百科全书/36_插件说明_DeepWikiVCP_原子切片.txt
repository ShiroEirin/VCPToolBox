[VCP百科全书] 插件说明——DeepWikiVCP（原子切片）

一、插件身份
- name: `DeepWikiVCP`
- displayName: `DeepWiki仓库文档检索`
- version: `2.1.0`
- pluginType: `synchronous`
- author: `infinite-vector`
- entryPoint: `node DeepWikiVCP.js`（nodejs）
- protocol: `stdio`
- timeout: `180000`（3分钟）
- command: `wiki_structure`, `wiki_content`, `wiki_ask`

二、核心能力
- 通过 DeepWiki 官方 MCP API 获取任意 GitHub 公开仓库的 AI 生成文档。
- 支持文档结构获取、完整内容读取、AI 智能问答、Deep Research 深度研究和多仓库联合查询。

三、命令与参数
1. `wiki_structure`：获取 GitHub仓库在 DeepWiki 上的文档目录结构
   - url (字符串, 必需): 仓库标识，支持 owner/repo 格式、GitHub URL 或 DeepWiki URL
2. `wiki_content`：读取 DeepWiki 上指定仓库的完整文档内容
   - url (字符串, 必需): 仓库标识 (owner/repo 格式)
3. `wiki_ask`：向 DeepWiki AI 提出关于 GitHub 仓库的问题
   - url (字符串, 必需): 仓库标识。多仓库用逗号分隔（最多10个）
   - question (字符串, 必需): 你想问的问题
   - deep_research (布尔, 可选): 设为 true 启用深度研究模式（最多5轮迭代检索）

四、配置参数（configSchema）
- `DEEPWIKI_PROXY` (string, optional): HTTP 代理地址，留空则继承系统代理
- `DEEPWIKI_GITHUB_TOKEN` (string, optional): GitHub PAT，用于查询私有仓库（预留）
- `DEEPWIKI_GITLAB_TOKEN` (string, optional): GitLab PAT，用于查询私有仓库（预留）
