# 一、定位（前后端配套双插件）

把本机 Wallpaper Engine（WE）库存壁纸作为聊天窗口动态背景。**service 插件 VCPWEWallpaper**（后端枚举+流式服务）+ **renderer 插件 VCPWEWallpaperUI**（前端选择器+播放面板）配合使用。

| 插件 | pluginType | 版本 | 职责 |
|---|---|---|---|
| VCPWEWallpaper | `service` | 0.1.0 | 发现本机 WE 安装、枚举壁纸库存、通过分布式服务器 Express 路由提供 inventory 与媒体流 |
| VCPWEWallpaperUI | `renderer` | 0.1.0 | 聊天窗口壁纸选择器 + 播放控制面板 + 断点续播 |

作者：PiCode（核心定位/枚举/流式逻辑移植自 elysia395/dsh-wallpaper-engine MIT；播放内核移植自 VChatDynamicWallpaper by 辉宝）

# 二、VCPWEWallpaper（后端 service，无 AI 命令）

## 路由（默认 5974 端口，VCPDistributedServer 主 Express 应用）

| 路由 | 说明 |
|---|---|
| `GET /vcp-we-wallpaper/inventory` | 壁纸库存 JSON（id/title/type/playable/media/preview/web），`?refresh=1` 绕过缓存重扫 |
| `GET /vcp-we-wallpaper/media/<token>` | 视频媒体流，支持 Range（拖进度条） |
| `GET /vcp-we-wallpaper/preview/<token>` | 预览图 |
| `GET /vcp-we-wallpaper/web/<token>/*` | web 类型壁纸目录子树托管，入口 HTML 自动注入 WE API 垫片 |

## 类型边界

- **Video**（mp4 等）与 **Web**（HTML）可动态呈现
- **Scene**（WE 原生 3D，内容封在私有 scene.pkg）与 Application 无法浏览器渲染，渲染端退化为静态预览图

## 安全模型

- media/preview：token = base64url(绝对路径)，逐文件白名单（仅 inventory 枚举过的文件可服务）
- web：逐目录白名单 + 路径归一化校验，未注册 token 一律 404
- inventory 缓存 5 分钟（LRU）

## 文件结构

```
VCPWEWallpaper/
├── we-wallpaper-service.js  # 入口：initialize + registerRoutes 协议
├── lib/locate.js            # Steam/WE 定位（注册表 HKCU\Software\Valve\Steam + libraryfolders.vdf + 多盘 SteamLibrary 探针）
├── lib/inventory.js         # 三源枚举（官方默认/我的项目/创意工坊订阅）+ project.json 分型 + MIME 表
├── lib/we-api-shim.js       # WE 私有 JS API 垫片（web 壁纸必需）
└── lib/media-server.js      # 四条路由 + Range 流式 + 目录托管 + 缓存
```

## WE API 垫片

浏览器里 WE 私有全局函数是 undefined，垫片在入口 HTML `<head>` 后注入早于壁纸脚本执行：`wallpaperPropertyListener`（setter 拦截回喂 project.json properties）、`wallpaperRegisterAudioListener`（128 段全零频谱 15Hz 空转）、`wallpaperRegisterMedia*Listener`（空实现）。注入属性 JSON 把 `</` 转义为 `<\/` 防 `</script>` 提前闭合。

# 三、VCPWEWallpaperUI（前端 renderer）

## 三种呈现形态（按壁纸能力自动分派）

| 形态 | 图层 | 适用 |
|---|---|---|
| `video` | `<video>` 硬解 | Video 类型壁纸 |
| `web` | `<iframe>` 隔离渲染 | Web 类型，service 端托管目录并注入垫片 |
| `image` | `<div>` 背景图 | Scene 类型或 web 载入超时降级兜底 |

## 核心功能

- 壁纸库网格选择器（预览图 + 形态徽章 + 标题搜索 + 类型过滤 + 每页 24 张分页）
- 重新扫描按钮（`?refresh=1` 强制重扫，回报新增/减少数）
- chat-header 控制面板：壁纸库/播放暂停/静音/背景显隐/音量/轮播/下一张
- 轮播（1/5/15/30/60 分钟间隔，仅 video+web 动态壁纸参与）
- 白屏保护（web 壁纸 8 秒未 load 自动降级静态预览图并本会话记住）
- 无缝循环 + 断点续播 + 窗口不可见即挂起（visibilitychange 暂停解码/卸载 iframe）
- 只取元数据（`<video preload="metadata">`，避免整文件缓冲）
- 互斥协调（激活时自动暂停 VChatDynamicWallpaper 背景视频）
- registry 暴露（destroy/pause/resume/openPicker/next/setRotate/state/active/kind）

## 设置（localStorage `vcpWeWallpaper.settings.v1`）

enabled / wallpaperId / wallpaperKind / playing / muted / volume / currentTime / visible / serverBase / filterType / panelCollapsed / rotate / rotateMinutes

# 四、启用前置条件

1. 启用分布式服务器 + VCPWEWallpaper service 插件
2. 启用 VCPWEWallpaperUI 前端插件，重启 VCPChat
3. web 壁纸需主程序 `main.html` 的 CSP 放通 `frame-src 'self' http://127.0.0.1:5974 http://localhost:5974`（本仓库已加；CSP 多策略取交集，无插件侧替代方案）

# 五、已知限制

- Scene 壁纸无法动态渲染（scene.pkg 私有二进制，需 WE 自家 3D 引擎）
- 音频律动类 web 壁纸静止（垫片喂全零频谱）
- 依赖外网 CDN 的 web 壁纸可能白屏（8 秒超时自动降级）
- 播放列表轮转为 v1.1 规划（当前 playlists 字段为占位空数组）
