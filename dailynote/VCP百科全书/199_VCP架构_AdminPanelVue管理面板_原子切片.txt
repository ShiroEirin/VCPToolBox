二、功能定位

AdminPanel-Vue 是 VCPToolBox 的新一代管理面板，替代了旧的纯 HTML/JS AdminPanel。采用 Vue 3 + Vite + TypeScript 构建，通过 Pinia 管理状态，vue-router 处理路由。面板提供完整的可视化管理能力，包括 RAG 参数调节、Agent 助手配置、插件启停管理等。

四、核心功能模块

1. RAG 调参面板：可视化调整 TagMemo 浪潮算法参数、测地线权重、EPA 配置等
2. Agent 管理：Agent Assistant 配置、积分排行榜 (agent-scores)、委托任务管理
3. 插件配置：插件启停、参数编辑、Manifest 可视化
4. 知识库监控：向量索引状态、WAL 健康、索引内存占用
5. 系统状态：服务器运行状态、API 健康检查、日志查看

五、与旧 AdminPanel 的关系

管理面板已从旧 AdminPanel (纯 HTML/JS) 迁移到 AdminPanel-Vue (Vue 3 SPA)。旧面板的相关功能正在逐步迁移，新功能直接在 Vue 版本中开发。

参考：166_更新 切片中提到 Agent 干活排行榜的 agent-scores.js 即位于 AdminPanel-Vue 中。
