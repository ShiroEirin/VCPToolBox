  1. 独立 Tag 字段（externalTag）优先使用，会覆盖 Content 中的 Tag 行
  2. 否则检测 Content 末行 Tag: 格式
  3. 两者都无则抛出错误（带详细提示信息）
- maid 支持 [文件夹]名字 语法，创建时会拆分 folder 与 actualMaidName。
- update 有安全门槛：target 长度必须 >= 15，否则直接拒绝。
- v3.0 常驻内存 FIFO 队列：所有文件变更通过单一队列执行，与 KnowledgeBaseManager 的 SQLite/Rust 索引队列协调，避免多 Agent 并发写入竞争。

三、Tag 处理函数

```javascript
// 检测 Content 最后一行是否为 Tag 行
function detectTagLine(content) {
    const lines = content.split('\n');
    if (lines.length === 0) {
        return { hasTag: false, lastLine: '', contentWithoutLastLine: content };
    }
    const lastLine = lines[lines.length - 1].trim();
    const tagPattern = /^Tag:\s*.+/i;
    const hasTag = tagPattern.test(lastLine);
    const contentWithoutLastLine = hasTag ? lines.slice(0, -1).join('\n') : content;
    return { hasTag, lastLine, contentWithoutLastLine };
}

// 修复 Tag 格式（统一为 "Tag: 关键词1, 关键词2" 标准格式）
function fixTagFormat(tagLine) {
    let fixed = tagLine.trim();
    fixed = fixed.replace(/^tag:\s*/i, 'Tag: ');
    if (!fixed.startsWith('Tag: ')) {
        fixed = 'Tag: ' + fixed;
    }
    const tagContent = fixed.substring(5).trim();
    let normalizedContent = tagContent
        .replace(/[\uff1a]/g, '')           // 移除中文冒号
        .replace(/[\uff0c]/g, ', ')         // 中文逗号转英文
        .replace(/[\u3001]/g, ', ')         // 顿号转英文逗号
        .replace(/[。.]+$/g, '');           // 移除末尾句号
    normalizedContent = normalizedContent
        .replace(/,\s*/g, ', ')
        .replace(/,\s{2,}/g, ', ')
        .replace(/\s+,/g, ',');
    normalizedContent = normalizedContent.replace(/\s{2,}/g, ' ').trim();
    return 'Tag: ' + normalizedContent;
}

// Tag 处理主函数（整合外部 Tag 和内容内 Tag）
async function processTags(contentText, externalTag) {
    // 优先使用外部传入的 Tag 参数
    if (externalTag && typeof externalTag === 'string' && externalTag.trim() !== '') {
        const fixedTag = fixTagFormat(externalTag);
        return contentText.trimEnd() + '\n' + fixedTag;
    }
    // 回退到检测内容中的 Tag 行
    const detection = detectTagLine(contentText);
    if (detection.hasTag) {
        const fixedTag = fixTagFormat(detection.lastLine);
        return detection.contentWithoutLastLine.trimEnd() + '\n' + fixedTag;
    } else {
        throw new Error("Tag is missing. Please provide a 'Tag' argument or add a 'Tag:' line at the end of the 'Content'.");
    }
}
```

四、边界与错误模式（JSON 格式返回）
- create 缺参数返回: `{ status: "error", error: "Invalid input for create: Missing maid/maidName, dateString/Date, or contentText/Content." }`
- update 非字符串参数返回: `{ status: "error", error: "Invalid arguments for update: 'target' and 'replace' must be strings." }`
- 未知命令返回: `{ status: "error", error: "Unknown command: 'xxx'. Use 'create' or 'update'." }`
- Tag 缺失返回: `{ status: "error", error: "Tag is missing. Please provide..." }`
