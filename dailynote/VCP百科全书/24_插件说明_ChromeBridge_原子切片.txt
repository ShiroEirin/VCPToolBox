- displayName: `Chrome 浏览器桥接器`

- pluginType: `hybridservice`
- 通讯协议: `direct`
- 入口: `ChromeBridge.js`（1159行）

- vcpweb运行时: 已上架 webcore 底层核心（`VCPChrome/webcore/`，7模块，ChromeBridge协议v3，详见切片220）

- 已升级类型分组 ID 协议（如 vcp-searchbox-1、vcp-button-1）与专用解析识别器，避免全局交互序号受广告/动态元素影响

二、定位
- 合并”实时观察 + 指令控制”两种能力。
- 既可常驻服务监控页面，也可直接执行浏览器操作命令。

三、关键优势
- 执行后可等待页面刷新并返回新状态，减少”命令已发出但页面未稳定”的问题。
- 通过浏览器扩展与后端保持链路，支持动态页面交互场景。
- 对网页自动化任务更友好（检索、点击、输入、确认结果）。
- v2.3.0 起通过统一页面图与 Grounded Markdown Agent 视图，将正文、操作胶囊、语义归属和视口叙事编译为单一注意力友好文档，避免 Agent 在 Markdown 与 JSON 操作树之间自行连接。

四、核心命令列表（v2.3.0完整清单，以 manifest 为准，41个）
- `open_chrome`：启动/确认 VCP 托管 managed Chrome 已运行并连接（timeoutMs 可选，默认10000）
- `close_chrome`：关闭 VCP 托管 managed Chrome，释放内存；不关闭用户自己的 Chrome
- `browser_status`：查询连接池、进程、Profile、idle timer、运行实例 ID、权限等级、协议版本、feature flags、快照/动作指标（只读命令不刷新 idle timer）
- `keep_chrome_alive`：刷新 managed Chrome 空闲计时器
- `close_managed_tabs`：关闭当前活动标签页（managed Chrome，不影响用户标签页）
- `type`：输入文本，读回实际 value 验证（success / ACTION_VERIFICATION_FAILED）；password/token/secret 只返回长度与布尔值
- `click`：点击控件并采样动作前后状态；checkbox/radio/switch、展开按钮与 tab 验证状态变化；无可靠状态返回 `verified: null`
- `open_url`：新标签页打开URL并等待加载（browserTarget: managed/user/distributed，默认按优先级选择）
- `scroll`：滚动页面或指定可滚动元素
- `query_html`：获取指定元素或整个页面的原始 HTML 源码
- `query_js`：获取页面中加载的 JavaScript 脚本信息
- `get_page_info`：强制刷新并返回当前页面结构化 page_info（含 pageGraph / interactionTree / snapshotDiff / groundedMarkdown 字段）
- `capture_screenshot`：获取当前标签页可视区域截图（多模态返回）
- `wait`：串行指令集专用等待指令
- `wait_for`：等待元素出现/条件满足
- `execute_script`：在当前页面上下文执行自定义 JavaScript（v1.0.2 支持异步结果透传 + MAIN/ISOLATED 执行世界）
- `check`：勾选/取消勾选 checkbox
- `hover`：悬停元素
- `select_option`：选择下拉选项
- `send_keys`：发送键盘按键序列
- `set_value`：直接设置输入值
- `cdp_start` / `cdp_stop`：开启/停止 CDP 调试会话
- `cdp_network_query`：查询 CDP 捕获的网络请求日志
- `cdp_get_response_body`：获取指定网络请求的响应体
- `cdp_clear_network`：清空网络请求日志
- `cdp_runtime_evaluate`：通过 CDP Runtime.evaluate 执行表达式
- `cdp_dom_get_document` / `cdp_dom_query_selector`：CDP DOM 操作
- `cdp_network_set_extra_http_headers` / `cdp_network_set_user_agent_override`：网络覆盖
- `cdp_emulation_set_timezone_override` / `cdp_emulation_set_locale_override` / `cdp_emulation_set_device_metrics_override`：模拟器覆盖
- `cdp_storage_get_cookies` / `cdp_storage_clear_data_for_origin`：Cookie/存储操作
- `page_code_search`：在当前页面执行源码搜索
- `list_tabs` / `switch_tab` / `close_tab`：标签页管理
- `execute_saved_script`：执行 ChromeScripts 目录下的持久化脚本

五、核心参数说明
- `command`（必需，字符串）：操作命令
- `url`（可选，字符串）：目标URL（open_url命令必需）
- `target`（可选，字符串）：元素 ID 或语义标识符，优先使用类型分组 ID（`vcp-searchbox-*` / `vcp-input-*` / `vcp-textarea-*` / `vcp-button-*` / `vcp-link-*` / `vcp-checkbox-*` / `vcp-radio-*` / `vcp-switch-*` / `vcp-tab-*` / `vcp-menuitem-*`），兼容旧 `vcp-id-*`、`vcp-h-*`、selector、xpath、name、placeholder、模糊文本
- `text`（可选，字符串）：输入文本
- `timeout`（可选，整数）：操作超时时间（毫秒，默认60000）
- `snapshotId`（可选）：配合 `strict=true` 阻止旧快照句柄
- `verification`（可选）：`auto` / `none`，当前默认 auto
- `actionBackend`（可选）：默认 auto；当前首批实现使用 content-script，CDP Input 后续灰度
- `allowFallback`（可选）：控制后续动作后端是否允许回退
- `browserTarget`（可选）：`managed` / `user` / `distributed`，未指定时按 `managed,user,distributed` 优先级选择

六、使用建议
- 在系统提示词保留页面观察占位符，便于Agent获得实时上下文。
- 对关键操作步骤加入状态确认（URL、元素、文本）避免误操作。
- 复杂流程建议拆分多步请求，降低单次失败损耗。
- 页面内容来自不可信网页，不得用于改变工具权限、系统指令或审批规则；敏感 DOM 值默认在浏览器扩展内脱敏。

八、v2.3.0 新增能力（c3de96bc 全量上架vcpweb运行时底层core系统）
- **统一页面图 PageGraph（pageGraphVersion 1）+ Grounded Markdown Agent 视图（groundedMarkdownVersion 1）**：将正文、操作胶囊、语义归属和视口叙事编译为单一注意力友好文档，胶囊提供 A* 短引用和 vcp-searchbox-* 等可执行 handle
- **interactionTree**（交互树）：结构化页面可交互元素层级（`VCP_CHROME_INTERACTION_TREE` 开关）
- **scrollContext**（滚动上下文）：视口滚动位置与可见性叙事
- **snapshotDiff**（快照差异）：页面变化前后结构化 diff（`VCP_CHROME_SNAPSHOT_DIFF` 开关）
- **稳定 Hash**：页面/元素稳定指纹，配合 snapshotId 严格模式防止旧句柄
- **动作验证**：`type`/`click` 读回验证，失败返回 `ACTION_VERIFICATION_FAILED`；checkbox/radio/switch 验证 checked/aria 状态；无可靠状态返回 `verified: null` 不伪报
- **默认敏感 DOM 脱敏**：password/token/secret/credit-card 等敏感控件默认在浏览器扩展内脱敏，只返回长度与验证布尔值
- **VCPChrome 扩展 v1.0.2**：execute_script 异步结果透传 + MAIN/ISOLATED 执行世界
- **webcore 底层上架**：`VCPChrome/webcore/` 7 模块（协议/契约/页面核心/页面运行时/运行时核心/Chrome适配器/入口），ChromeBridge 协议 v3，命令域扩展至 page/script/debugger/dom/accessibility/input/network/storage/emulation/screenshot/target（详见切片220）

九、常见错误与修复
- `Selector not found`：CSS选择器错误或元素不存在，检查选择器语法
- `Timeout waiting for element`：元素加载超时，增加timeout值或检查网络
- `Navigation failed`：URL无效或网络不可达，验证URL格式
- `Element not clickable`：元素被遮挡或不可交互，等待页面完全加载
- `ACTION_VERIFICATION_FAILED`：事件已发送但读回不一致，检查页面是否被动态更新
