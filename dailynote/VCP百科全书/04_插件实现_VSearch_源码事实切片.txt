二、行为事实（代码级）
- 必填参数是 SearchTopic 与 Keywords，缺失即返回错误。
- Keywords 支持分隔符：英文逗号、中文逗号、换行。
- ShowURL 支持布尔 true 或字符串 'true' 两种打开方式。
- 执行模型为分批并发：按 CONCURRENCY 切块，逐块 Promise.all 并发检索。
- v1.1.0 新增 SearchMode 参数，支持多种搜索后端：
  - grounding (Google搜索)
  - grok (Grok内置搜索)
  - tavily (Tavily外部搜索)
  - kimisearch (Kimi Search 外部搜索，默认模式)
- kimisearch 模式支持 KimiSearchMaxResults 和 KimiSearchIncludeContent 配置。
- tavily/kimisearch 模式支持二阶总结（SummaryKey/SummaryUrl/SummaryModel）。

三、输出结构
- 统一输出标题"VSearch 检索报告"。
- 每个关键词单独成段，结构为"### 关键词: ... + 搜索结果"。

四、配置项（configSchema）
- VSearchKey: API Key
- VSearchUrl: API 端点 URL
- VSearchModel: Grounding 模式模型名
- GrokModel: Grok 模式模型名
- TavilyKey / TavilyModel: Tavily 模式配置
- MaxConcurrent: 并发队列上限
- KimiSearchUrl / KimiSearchKey / KimiSearchMaxResults / KimiSearchIncludeContent: KimiSearch 模式配置
- SummaryKey / SummaryUrl / SummaryModel: 二阶总结专用配置
