二、功能定位

Logmodules 是 VCPChat 的日志查看器模块，以独立 Electron 窗口形式运行。它通过轮询后端 API 获取实时日志，支持预设过滤、自定义关键词搜索、正/逆序显示、行数限制等功能，为开发者提供便捷的日志排查工具。

四、核心逻辑 (log.js)

1. API 通信 (行1)
   - const api = window.utilityAPI || window.electronAPI

2. 存储键 (行3-6)
   ```
   STORAGE_KEYS = {
       lineLimit: 'vcp-log-center-line-limit',
       reverseOrder: 'vcp-log-center-reverse-order'
   }
   ```

3. 预设过滤器 (行8)
   PRESET_FILTERS = ['IP', 'TOOL', 'RAG', 'POST', 'PLUGIN', 'ERROR']

4. 轮询配置 (行9)
   POLL_INTERVAL_MS = 1800（1.8秒轮询间隔）

5. 全局状态 (行11-23)
   - serverBaseUrl / apiAuthHeader — API 地址和认证
   - allLines — 全部日志行数组
   - currentOffset — 当前偏移量
   - currentLogPath — 当前日志文件路径
   - isReverseOrder — 是否逆序显示
   - lineLimit — 行数限制 (默认 500)
   - pollTimer — 轮询定时器
   - isLoading — 加载中标志
   - activePreset — 当前激活的预设过滤器
   - currentFilter — 当前自定义过滤词
   - scrollHideTimer / suppressScrollReveal — 滚动隐藏控制

6. DOM 元素引用 (行25-30)
   - status — 日志状态指示
   - meta — 元数据显示
   - lines — 日志行容器
   - empty — 空状态提示
   - toast — 通知提示

七、功能特性

1. 实时轮询：1.8秒间隔自动拉取最新日志
2. 预设过滤：IP/TOOL/RAG/POST/PLUGIN/ERROR 六大类快捷过滤
3. 自定义搜索：关键词搜索
4. 正/逆序显示：可切换日志排列顺序
5. 行数限制：可配置最大显示行数（默认 500）
6. 清空后端日志：通过 API 清空后端日志文件
7. 本地存储：行数限制和逆序设置持久化到 localStorage
8. 主题适配：支持亮色/暗色主题自动切换
