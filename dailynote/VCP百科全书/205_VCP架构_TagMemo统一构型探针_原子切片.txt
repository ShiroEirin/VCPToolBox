二、功能定位

tagmemo_unified_geometry_probe.js 是一个只读离线分析脚本，用于验证 TagMemo V9.1 统一几何构型的数学一致性。它直接从 SQLite 事实层重建传播核，不初始化 KnowledgeBaseManager，不写任何数据。

源码注释 (tagmemo_unified_geometry_probe.js 行3-19)：
```
/**
 * TagMemo 统一几何构型离线探针
 *
 * 目标：
 * 1. 从现有 SQLite 事实层重建 V9.1 风格有向传播核；
 * 2. 比较有限跳软非回溯脉冲场、节点 Resolvent、边状态非回溯 Resolvent；
 * 3. 检验场诱导软域与候选 Tag 曲线几何是否给出一致读出；
 * 4. 使用拓扑-only 与随机场消融，避免仅凭"都用了同一张图"得出循环结论。
 *
 * 本脚本只以 readonly + query_only 打开数据库，不初始化 KnowledgeBaseManager，
 * 不写 SQLite、WAL、配置或派生资产。
 *
 * 用法：
 *   node scripts/tagmemo_unified_geometry_probe.js
 *   node scripts/tagmemo_unified_geometry_probe.js --seeds "TagA,TagB" --probes 12
 *   node scripts/tagmemo_unified_geometry_probe.js --db /data/VectorStore/knowledge_base.sqlite --json report.json
 */
```

五、分析目标

1. 有向传播核重建：从 SQLite file_tags 事实层重建 V9.1 风格有向传播核
2. 脉冲场比较：有限跳软非回溯脉冲场
3. Resolvent 比较：节点 Resolvent vs 边状态非回溯 Resolvent
4. 几何一致性检验：场诱导软域与候选 Tag 曲线几何是否给出一致读出
5. 消融实验：拓扑-only 与随机场消融，避免循环结论

六、V3.1 特性 (bat 行70-73)

- [动力学] 严格去源场、等长核心域、尾部质量与支持扩张
- [尺度] alpha=0.05 至 1.00 低尺度加密；hops=1,2,4
- [几何] 软域有界路径质量、不可定义样本过滤及每查询 100 次随机消融

七、依赖
