## 核心结论
- 版本：1.0.0，类型：synchronous，协议：stdio，超时：180000ms（3分钟）
- 入口：`python digital_oracle_vcp.py`（Python，要求 >=3.10）
- 允许 AI 手动选择金融信源，一键拉取全球宏观、利率、商品、股票、加密、预测市场与期权数据，返回结构化结果
- 支持信源：polymarket、kalshi、yahoo、treasury、cftc、coingecko、deribit_futures、deribit_options、fear_greed、cme_fedwatch、worldbank、bis、web、yfinance_options、edgar
- 提供 ListProviders（查看信源）、FetchMarketData（定向抓取）、GetGlobalMacroDashboard（全球面板快照）三个命令

## 工作机制
VCP AI 选择信源 → 发起 FetchMarketData 命令 → digital_oracle_vcp.py 调用对应上游信源 API → 返回结构化 JSON 结果 → VCP AI 基于结果进行分析推理

GetGlobalMacroDashboard 会并行抓取多个核心维度：恐惧贪婪指数、美联储概率、美债收益率、黄金、原油、比特币期限结构、加密现货、主要风险资产等

## 使用/排障边界
- 推荐先用 ListProviders 查看可选信源，再按问题选择最合适的 1~4 个维度
- provider/source 参数也可用平铺方式传参（如直接写 symbol=GC=F 而非 params JSON）
- edgar 信源需要配置 DIGITAL_ORACLE_SEC_EMAIL（作为 SEC User-Agent）
- yahoo: symbol, interval, limit, start_date, end_date
- polymarket: slug_contains, title_contains, limit
- yfinance_options: ticker, expiration
- 常见错误：Python 依赖缺失、SEC 邮箱未配置（edgar 信源）、网络代理不通

## 命令与参数
| command | commandIdentifier | 说明 |
|---------|-------------------|------|
| ListProviders | DigitalOracleListProviders | 列出全部金融信源、用途与常用参数 |
| FetchMarketData | DigitalOracleFetchMarketData | 手动指定信源并立即抓取数据（核心命令） |
| GetGlobalMacroDashboard | DigitalOracleGlobalMacroDashboard | 一键并行拉取全球金融监控面板快照 |

FetchMarketData 参数：provider/source（必需，信源标识）、params（可选，JSON字符串或平铺参数）
GetGlobalMacroDashboard 参数：risk_assets（可选，默认 SPY,QQQ,GC=F,CL=F,BTC-USD）、coin_ids（可选，默认 bitcoin,ethereum）、countries（可选，默认 US,CN,JP,EU）

## 配置参数（configSchema）
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| DIGITAL_ORACLE_SEC_EMAIL | string | (空) | SEC EDGAR 信源所需邮箱，仅调用 edgar 信源时必需 |
| DIGITAL_ORACLE_DEBUG | boolean | false | 是否输出调试级错误堆栈到 details 字段 |
