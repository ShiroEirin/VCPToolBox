## 核心结论
Chat 的消息渲染正在从「一次性 innerHTML + 全局重绘」重构为**带岛屿（island）、带沙箱、带 worker 的分层渲染架构**。`39cbd6e6` 单提交 +12,308/−11,746 几乎是**推倒重建**。

## 从模块名读出的架构
| 模块 | 推测职责 |
|---|---|
| `renderTemplateCompiler.js`（1,236 行） | **模板编译器**——把消息内容编译成可增量更新的渲染指令，而不是每次重解析 |
| `streamIslandGate.js`（244） | **流式岛屿门**——决定哪些片段可以独立更新（岛屿），哪些必须整体重绘 |
| `strictAnimationIsland.js`（112） | **严格动画岛屿**——动画只能在岛屿内运行，不得污染全局 |
| `animationMountController.js`（177） | 动画挂载控制器——控制动画生命周期 |
| `offscreenDomWindow.js`（204） | **离屏 DOM 窗口**——在不可见窗口预渲染 |
| `renderWorker.js` / `renderWorkerClient.js` / `renderWorkerRuntime.js` | **渲染 worker 三件套**——主线程/worker 分离 |
| `vcpDocumentScanner.js`（195） / `vcpParseContext.js`（180） | VCP 文档扫描与解析上下文——把消息拆成可识别的结构块 |
| `mathRenderer.js`（194） | 数学公式渲染（对应 `06ef625c katex原生多线程渲染`） |
| `messagePreviewText.js`（35） | 预览文本提取（侧栏/列表用） |
