[VCP百科全书] 插件说明——NanoBananaGen2（原子切片）

一、插件身份
- name: NanoBananaGen2
- displayName: NanoBanana 图像生成 (自定义渠道)
- version: 1.2.0（2026-09-02 第13次上游合并升级；1.1.0→1.2.0）
- pluginType: synchronous
- command: NanoBananaGenerateImage, NanoBananaEditImage, NanoBananaComposeImage
- 调用时使用工具名 NanoBananaGen2

二、核心能力
- 使用 Vercel 接口调用 Google Gemini 3 pro Image Preview 模型进行高级的图像生成和编辑。支持代理和多密钥随机选择。
- 提供可调用命令：NanoBananaGenerateImage、NanoBananaEditImage、NanoBananaComposeImage。

三、占位符与注入点
- systemPromptPlaceholders: 无

四、配置重点
- 优先核对插件目录内的 plugin-manifest.json(.block) 与 config.env.example 必填项。
- 外部API类插件重点检查：密钥、端点、超时、代理与速率限制。

五、排障建议
- 插件无响应：先检查 manifest 启用状态、入口脚本、运行时依赖。
- 结果异常：核对命令名与参数字段，再查看插件目录缓存/日志文件。

六、调用示例

1. generate - 生成图像
<<<[TOOL_REQUEST]>>>
tool_name:「始」NanoBananaGen2「末」,
command:「始」NanoBananaGenerateImage「末」,
prompt:「始」描述你想要生成的图像「末」
<<<[END_TOOL_REQUEST]>>>

2. edit - 编辑图像
<<<[TOOL_REQUEST]>>>
tool_name:「始」NanoBananaGen2「末」,
command:「始」NanoBananaEditImage「末」,
image:「始」base64_image_data「末」,
prompt:「始」编辑指令「末」
<<<[END_TOOL_REQUEST]>>>

3. compose - 合成图像
<<<[TOOL_REQUEST]>>>
tool_name:「始」NanoBananaGen2「末」,
command:「始」NanoBananaComposeImage「末」,
images:「始」[image1, image2]「末」
<<<[END_TOOL_REQUEST]>>>

十二、v1.2.0 变更（原「追加切片」内容并入，2026-09-02；第13次上游合并 83e4a4f5 + 411dc628 PR#459）

1. displayName 从「Gemini 3 NanoBanana 图像生成 (官方)」改为「NanoBanana 图像生成 (自定义渠道)」，描述明确「可接入任何 /v1/chat/completions 兼容服务、多渠道绑定轮询（URL+KEY+多 MODEL 对应）、单渠道多模型随机」。
2. 渠道故障转移（channel failover）：请求失败自动切换下一渠道。
3. details 响应裁剪：base64 图片数据不再塞进 details（防止上下文爆炸）。
4. http 代理与本地 URL 修复。
5. 新增 config.env 参数：SAFETY_BYPASS_TEXT（追加到 prompt 尾部的破限文本，留空则完全不追加）、MAX_RETRIES=2（429/503 最大重试次数）、RETRY_BASE_DELAY_MS=2000、USE_PUBLIC_URL 说明修正（true=输出不带端口的公网 URL，需反代已做端口映射）。
6. plugin-manifest.json configSchema 同步登记 USE_PUBLIC_URL / SAFETY_BYPASS_TEXT / MAX_RETRIES / RETRY_BASE_DELAY_MS。
7. 新增 package.json（插件本地依赖声明）。
