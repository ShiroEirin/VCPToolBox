## asyncResultStore 的硬规则（源码逐字）
```js
const { invalidPath, resolveSafePath, assertSafePath } = require('./safeFilePath');

// Identifiers are names, never paths. Reject percent escapes as well: decode once only.
function validateResultId(value, maxLength = 120) {
    if (typeof value !== 'string' || value.length > maxLength
        || !/^[A-Za-z0-9_-][A-Za-z0-9_.-]*$/.test(value)
        || value.includes('..') || value.endsWith('.'))
        throw invalidPath('Invalid task or plugin identifier');
    return value;
}
```
- **复用 277 的 `safeFilePath`**：`resolveSafePath` / `assertSafePath` / `invalidPath` 三条一起 import，说明路径安全已形成单一入口。
- 标识符是**名字不是路径**：只允许 `[A-Za-z0-9_-]` 开头，后续可含 `.`，但**禁止 `..`、禁止尾随点**。
- 注释明确处理百分号转义：`Reject percent escapes as well: decode once only.`——只解一次码，防双重编码绕过。
- `resultPath(root, pluginName, taskId)` 对两个标识符分别校验（pluginName 上限 100、taskId 上限 120）。
