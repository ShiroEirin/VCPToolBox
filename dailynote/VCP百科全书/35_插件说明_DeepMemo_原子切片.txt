二、功能定位
DeepMemo v2.0.0 是基于 VCP-CDS (VCP Chat Data Service) 中央聊天数据服务的深度回忆插件。通过关键词从聊天记录中检索相关上下文，支持高级搜索语法（精确短语、权重调整、负向排除、OR逻辑）和可选的 Rerank 精排功能。

v2.0.0 重大变更：
- 从旧版独立 Rust EXE 架构迁移为 VCP-CDS 中央搜索适配器
- 插件类型从 synchronous 升级为 hybridservice
- 新增 rerank 精排参数（第5个调用参数）
- 新增 16 个 configSchema 配置项，包括完整的 Rerank 配置链

三、配置参数 (configSchema)
| 参数 | 类型 | 说明 |
|------|------|------|
| DeepMemoBackend | string | 后端服务地址 |
| DeepMemoLegacyFallback | boolean | 旧版回退开关 |

| DeepMemoCandidateLimit | integer | 候选结果上限 |
| DeepMemoResultLimit | integer | 最终结果上限 |
| DeepMemoTimeoutMs | integer | 请求超时毫秒 |

| RerankApi | string | Rerank API Key |
| RerankModel | string | Rerank 模型名 |
| RerankCandidateMultiplier | integer | 候选倍率 |
| RerankMaxDocumentsPerBatch | integer | 每批文档上限 |
| RerankMaxTokensPerBatch | integer | 每批 Token 上限 |
| RerankTimeoutMs | integer | Rerank 超时毫秒 |

四、Feature Flags（与 VCP-CDS 联动）
| Flag | 默认值 | 说明 |
|------|--------|------|
| DeepMemoUseCentralSearch | False | DeepMemo 使用中央搜索（关闭时使用旧 EXE） |
| DeepMemoLegacyFallback | True | 旧版回退 |

关闭 VCP-CDS 后 (`ChatDataServiceEnabled=False`)：DeepMemo 继续使用旧 EXE，中央数据库保留供诊断或后续恢复。

五、调用命令列表

1. DeepMemo - 深度回忆检索
   功能描述：根据关键词在指定女仆的记忆库中进行搜索，返回格式化的对话片段

   参数列表：
   - tool_name (string, 必需): 固定为「始」DeepMemo「末」
   - maid (string, 必需): 发起请求的AI女仆的中文名（如小克、小吉、小娜），通过名字匹配记忆
   - keyword (string, 必需): 用于搜索的关键词，多个关键词可用英文逗号、中文逗号或空格分隔
   - window_size (integer, 可选, 范围1-20, 默认10): 上下文窗口大小，代表以匹配到的对话为中心，向前和向后各取多少轮对话
   - rerank (boolean, 可选): true 表示本次请求精排，false 表示本次强制跳过；省略时遵循服务端 RerankSearch 配置

   高级搜索语法（keyword参数）：
   - 普通词：VCP
   - 精确短语："VCP服务器"
   - 正向加权 (0.0-2.0)：(重要概念:1.5)
   - 负向排除：[闲聊] //不支持权重
   - OR逻辑：{破解|渗透|测试} //支持正向权重
   - 组合示例：[闲聊],[日常对话],(技术:1.2),(代码:1.1),{bug|修复|问题:1.3}

   完整调用格式（含 rerank）：
   <<<[TOOL_REQUEST]>>>
   maid:「始」小克「末」,
   tool_name:「始」DeepMemo「末」,
   keyword:「始」深度回忆,系统,构想「末」,
   window_size:「始」6「末」,
   rerank:「始」true「末」
   <<<[END_TOOL_REQUEST]>>>
   返回值说明：返回多个回忆片段的格式化字符串，每个片段包含相关对话内容；失败时返回错误信息

七、VCP-CDS 身份解析
DeepMemo 请求的身份解析位于 VCP-CDS 的 DeepMemo 请求规范化层，不位于 Tantivy 层。
解析顺序：
1. ownerId 精确定位
2. Agent 显示名精确匹配
3. 旧 maid 参数唯一包含匹配
4. 多个包含候选返回 AMBIGUOUS_IDENTITY

示例：maid = Nova → display_name = vcp小助手Nova，当且仅当包含结果唯一时解析为对应 Agent。Tantivy 始终接收解析后的精确 Owner ID，不执行名称猜测。

八、注意事项与限制
1. 女仆名称匹配：maid 参数通过 VCP-CDS 身份解析层处理，支持精确匹配和唯一包含匹配
2. Rerank 精排：rerank 参数为 true/false/省略三态，省略时遵循服务端 RerankSearch 配置
3. 通信超时：30000ms (30秒)，相比旧版的 180 秒大幅缩短，因为搜索由 VCP-CDS 本地服务执行
4. 旧版回退：DeepMemoLegacyFallback=True 时，若中央搜索不可用可回退到旧 EXE
5. 返回格式：[回忆片段N：\n发言人: 内容\n...]，多个片段之间用空行分隔
