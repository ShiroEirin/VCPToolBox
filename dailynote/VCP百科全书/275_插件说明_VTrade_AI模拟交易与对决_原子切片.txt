## 核心结论
VTrade 是 VCP 首个「本地行情 + Agent 与人共用账本 + 人机对决」三合一插件。它不接券商、不联网取数，直接读本机通达信 `vipdoc` 目录的全市场日线；Agent 与人共享同一套虚拟账本；对决让玩家与 Agent 在同一段历史行情上逐日决定仓位，并与随机操作者比成绩。

## 三种形态
1. **看盘**（默认布局）：在「设置 → 数据 → 看盘数据目录」填写通达信 `vipdoc` 目录后，列表展示全部股票、指数与基金；支持代码／名称／拼音首字母搜索、列排序、方向键逐只切换；底部切换 A 股、创业板、科创板、北交所、指数、基金、自选与自建板块。
2. **模拟交易**：一次模拟交易 = 一个虚拟账户 + 一条按数据日推进的时间线；记录模拟意图后点击「推进到下一数据日」查看虚拟成交，持仓、委托、日志与资金曲线随之更新。自选与板块只整理视图，不限制可交易范围；账本仅记录实际用到的股票。
3. **对决**（`/admin_api/vtrade/duel/`）：单练／观战 Agent／与 Agent 同场，一局 60 个交易日。

## 图表与 UI
- K 线、成交量与资金曲线由插件自带画布引擎绘制（`frontend/chart-engine.mjs`、`chart-scale.mjs`），不依赖第三方图表库。
- 指标系统分三层：`indicators.mjs`（计算）→ `indicator-layer.mjs`（渲染层）→ `indicator-editor.mjs`（编辑 UI），样式独立在 `indicator-ui.css`。
- 控件使用固定版本的 VCPUI 组件（`ui/vcp-ui.js` 117KB 自带，不走外部 CDN）。
- 模拟交易中图表只显示到当前模拟日；买卖箭头只来自虚拟成交；持仓线是当前均摊成本；水平参考线只留在当前页面，不创建条件单。
- 首次打开页面显示免责声明与数据获取说明。

## 六个可注册插槽（`SLOTS.md`）
行情源、指标与信号、股票池、撮合规则、券商接口、AI 工具——全部可替换，核心与网络解耦。

## 接入与配置
- 工具名 `VTrade`，提示词用 `{{VCPVTrade}}` 注入；`AI_GUIDE.md` 是给 Agent 的操作说明。
- 页面挂在主后端 `/admin_api/vtrade/`（管理面板端口同可用），页面与 API 都位于现有管理员认证之后，不新增匿名接口；管理面板无需改动。
- 存储默认 `Plugin/VTrade/data/`（已被 `.gitignore` 排除）；本机 `config.env` 可设 `VTRADE_DATA_DIR`、`VTRADE_SOURCES_FILE`、`VTRADE_ADAPTERS`。
- 关闭插件时加载器调用 `shutdown()`；direct 插件更新需正常重启。
- 需要 Node.js 22.7 或更新版本；独立预览与核心不需要 npm 依赖（`node preview.cjs`）。

## 安全边界（README 原文要点）
- 核心不联网；内置合成日线只用于离线演示；行情由用户自行下载或导入。
- AI 工具**不接受服务器路径、远程 URL 或下载指令**，只能同步管理员已配置的来源；导入数据、来源设置与看盘只在管理员页面进行（分别走 `/api/import`、`/api/settings`、`/api/market`），工具调用无法访问——因此模拟交易中的 Agent 拿不到模拟日之后的行情。
- `agentName`、`maid` 都不是身份凭据；本版本面向管理员控制的受信任 Agent，所有运行由同一管理员管理，不提供多租户账户隔离。
- 预览服务只监听 `127.0.0.1`；访问凭据放 URL fragment，页面读取后移除。
