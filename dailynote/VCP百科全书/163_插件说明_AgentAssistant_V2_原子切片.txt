## 核心结论
- AgentAssistant 当前是 `hybridservice/direct` 插件，version 2.0.0，timeout 358000ms。
- 唯一公开命令为 `AskMaidAgent`（commandIdentifier）。
- 命令支持即时通讯、`timely_contact` 定时联络、`task_delegation` 异步委托、`query_delegation` 进度查询和单次 `inject_tools` 临时工具注入。
- 异步委托通过 `[[TaskComplete]]`、`[[TaskFailed]]` 和 `[[NextHeartbeat::秒数]]` 控制完成、失败和下一次心跳。
- 完成结果可写入归档文件，并向 `/plugin-callback/AgentAssistant/{delegationId}` 回调。
- webSocketPush 已启用，messageType=plugin_callback_notification。

## 命令与参数
命令 `AskMaidAgent`，参数如下：
- `agent_name`（必需，字符串）：要调用的 Agent 的准确名称
- `prompt`（必需，字符串）：对该 Agent 提出的任务、问题或指令
- `timely_contact`（可选，字符串）：设置未来时间点发送此通讯，格式 YYYY-MM-DD-HH:mm
- `temporary_contact`（可选，布尔）：设为 true 时通讯不带历史上下文
- `task_delegation`（可选，布尔）：设为 true 时启用异步委托模式
- `query_delegation`（可选，字符串）：传入正在执行的 delegationId 查询进度
- `inject_tools`（可选，字符串）：传入逗号分隔的工具名列表（如 VCPForum,ComfyUIGen），仅对本次联络/委托生效

## 配置参数（configSchema）
| 参数 | 类型 | 说明 |
|------|------|--------|
| AGENT_ASSISTANT_MAX_HISTORY_ROUNDS | integer | 最大历史对话轮次 |
| AGENT_ASSISTANT_CONTEXT_TTL_HOURS | integer | 上下文存活时间（小时） |

## 工作机制
`AskMaidAgent` 参数 → 校验 Agent 与通讯模式 → 即时请求、定时任务或后台委托循环 → 解析完成/失败/延迟标记 → 返回文本结果、动态占位符或归档路径。

异步模式会立即返回 `{{VCP_ASYNC_RESULT::AgentAssistant::{delegationId}}}` 占位符；运行中的任务保存在内存状态中，完成记录还可从 `VCPAsyncResults` 与 AgentTask 归档查询。

## 使用/排障边界
- 适合把明确任务交给已配置的 Agent，或查询异步委托进度。
- 不适合把 `inject_tools` 当作永久修改 Agent 能力；它只对本次通讯有效。
- 临时工具组会在 system 中明确标注，方便 Agent 区分长期能力与临时能力。
- 若某工具缺少详细命令描述，将回退到该插件 manifest 的基础描述。
- 常见错误包括 Agent 名称不存在、delegationId 无效、委托没有输出终态标记、配置的回调地址不可达。
- 与 AgentMessage 的区别：AgentAssistant 管理 Agent 对话上下文与委托生命周期，不只是发送单条消息。

## 历史与兼容性
