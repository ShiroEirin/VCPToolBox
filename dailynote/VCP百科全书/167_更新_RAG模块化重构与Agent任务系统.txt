3. LRS三元组模型

| 参数 | 含义 | 计算来源 | 影响 |
|------|------|----------|------|
| L | LogicDepth | EPA分析 | 逻辑深度越高，K值越大 |
| R | Resonance | EPA分析 | 共鸣度越高，权重越大 |
| S | SemanticWidth | 上下文向量 | 语义宽度越高，噪声惩罚越大 |

4. Sigmoid动态调整

```javascript
const betaInput = L * Math.log(1 + R + 1) - S * noise_penalty;
const beta = this.sigmoid(betaInput);  // 压缩到0-1范围
const finalTagWeight = min + beta * (max - min);
```

五、CacheManager - 缓存管理器（原RAGCacheManager）

1. 功能定位
通用缓存管理组件，实现LRU(最近最少使用)+TTL(生存时间)双重策略。

2. 构造函数参数

```javascript
constructor(name, options = {
    maxSize: 100,      // 最大条目数
    ttl: 3600000,      // 生存时间(ms)，默认1小时
    enabled: true      // 是否启用
})
```

3. 方法列表（基于原文，待核验当前实现）

| 方法 | 参数 | 返回值 | 功能 |
|------|------|--------|------|
| get | key: string | any | 获取缓存值 |
| set | key: string, data: any | void | 设置缓存值 |
| clear | - | number | 清空缓存，返回清除数量 |
| startCleanupTask | - | void | 启动定时清理任务 |
| stopCleanupTask | - | void | 停止定时清理任务 |
| getStats | - | object | 获取统计信息 |
| generateHashKey | content: string | string | 生成SHA256哈希键 |

4. 统计信息格式

```javascript
{
    name: "缓存名称",
    size: 当前条目数,
    maxSize: 最大容量,
    hits: 命中次数,
    misses: 未命中次数,
    hitRate: "命中率百分比",
    ttl: 生存时间
}
```

5. LRU实现原理

利用JavaScript Map的插入顺序特性：
- get操作：删除后重新插入，移到末尾(最新)
- set操作：超出容量时删除第一个(最旧)

六、TimeDecayProcessor - 时间衰减处理器
⚠️ 当前Plugin/RAGDiaryPlugin/目录中未找到TimeDecayProcessor.js独立文件，时间衰减逻辑可能已合并到RAGDiaryPlugin.js中。以下为原文内容保留。

1. 功能定位
实现时间衰减重排算法，让较新的日记本条目获得更高权重。

2. 语法格式

```
::TimeDecay[halfLife]|[minScore]|[whitelistTags]
```

| 参数 | 类型 | 可选 | 默认值 | 说明 |
|------|------|------|--------|------|
| halfLife | int | 是 | 30 | 半衰期天数 |
| minScore | float | 是 | 0.5 | 最小保留分数 |
| whitelistTags | string[] | 是 | [] | 目标标签白名单 |

3. 使用示例

```
::TimeDecay              # 使用默认参数(半衰期30天)
::TimeDecay7             # 半衰期7天
::TimeDecay7|0.3         # 半衰期7天，最小分数0.3
::TimeDecay7|0.3|工作,项目  # 只处理包含"工作"或"项目"标签的条目
```

4. 衰减公式

```javascript
const decayFactor = Math.pow(0.5, diffDays / halfLife);
const newScore = originalScore * decayFactor;
```

衰减效果表(半衰期=7天)：
| 时间差 | 衰减系数 | 剩余权重 |
|--------|---------|---------|
| 0天 | 1.000 | 100% |
| 3.5天 | 0.707 | 70.7% |
| 7天 | 0.500 | 50% |
| 14天 | 0.250 | 25% |
| 21天 | 0.125 | 12.5% |
