3. RAG时间衰减重排功能（日月同辉V6核心）

文件位置：Plugin/RAGDiaryPlugin/RAGDiaryPlugin.js

Commit: 64b7726 feat(rag): 新增基于时间衰减的RAG结果重排功能

技术原理：
在RAG检索结果排序时，不仅考虑语义相似度，还引入时间衰减因子，
使得较新的记忆片段获得更高权重。

算法公式：
```
最终得分 = 语义相似度 × 时间衰减系数
时间衰减系数 = e^(-λ × Δt)
```
其中λ为衰减系数，Δt为时间差。

配置参数：
```env
RAG_TIME_DECAY_ENABLED=true
RAG_TIME_DECAY_LAMBDA=0.001
```

五、使用指南

1. 启用Agent排行榜

在AdminPanel-Vue界面中，点击"Agent积分"标签页即可查看排行榜。
支持手动刷新和自动更新（每5分钟）。

2. 配置积分规则

编辑Plugin/AgentAssistant/config.env：
```env
DELEGATION_POINTS_COMPLETE=20
DELEGATION_POINTS_PARTIAL=10
```

3. 调整RAG时间衰减

编辑Plugin/RAGDiaryPlugin/config.env：
```env
# 值越大，旧记忆衰减越快
RAG_TIME_DECAY_LAMBDA=0.001
```
