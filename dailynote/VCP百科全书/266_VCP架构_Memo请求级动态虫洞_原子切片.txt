二、核心定义（文档原文）

```text
动态虫洞是请求级状态，不写回图资产。
```

一条动态虫洞必须**同时**满足四个条件：

| # | 条件 |
|---|---|
| 1 | 当前源节点的**完整 CSR 行**中存在**正权重历史出边** |
| 2 | 目标向量与来源支流**更深层的金字塔残差**达到共鸣阈值 |
| 3 | 考虑**立即回流惩罚**后的预估注入电流达到最低注入门槛 |
| 4 | 在**动态保留席位**内胜出 |

并且有一条极关键的限制：

```text
普通路径仍使用原静态权重顺序。动态席位包含在原邻居名额之内，不是额外追加出边。
```

也就是：虫洞**不扩大邻居名额**，只是在原有席位里换人。这条决定了它不会让检索面膨胀。

三、残差与来源层级（文档 2.1 原文要点）

金字塔分析保留每个实际分析层投影**之前**的残差；这些向量原本已用于该层检索，**不再次生成查询向量**。

种子归属它**首次出现在金字塔中的层级**。来源层为 `L` 时，只允许层号 **> L** 的残差支持动态虫洞。由此推出五条行为：

```text
- 第一层源节点可以受到后续残差支流支持。
- 最后一层源节点没有更深层残差，不产生动态支持。
- 只有一层分析结果时，不产生动态虫洞。
- 传播后继承来源层级，不重新运行金字塔分析。
- 多条路径合并为同一传播状态时保留最早来源层级，允许其后续残差支持。
```

最后一条作者自己加了限定：

```text
最后一项是合并状态下的层级策略，不是完整的多源血缘跟踪，
不能据此声称已实现精确多源会师诊断。
```

四、共鸣与排序（文档 2.2 原文）

```text
目标共鸣为可用更深层残差与目标原始向量的正余弦最大值，限定在 0 至 1。
```

即：共鸣是**正部余弦**（负相关不计为共鸣），且被截断在 [0,1]。

七、风险

1. **单层金字塔不产生虫洞**：若某次查询只跑出一层分析，该功能静默不生效，容易被误判为「功能坏了」。
2. **层级继承 ≠ 多源血缘**：作者已明确否认精确多源会师诊断，任何基于此的强断言都是过度解读。
3. **官方未验证 Windows release 产物加载**，本机需自行冒烟。
4. 动态席位挤占原邻居名额：理论上存在「动态候选挤掉更优静态邻居」的可能，官方文档未给出该情形的兜底说明。
5. 虫洞是请求级、不落盘，因此**不可复现**为持久化行为——同样的输入在不同图状态下可能给出不同虫洞，除非图与残差完全一致。
