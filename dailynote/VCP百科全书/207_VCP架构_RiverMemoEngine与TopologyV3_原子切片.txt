## 核心结论
RiverMemo Topology V3 是 VCP 记忆系统的生产级连续信息场检索引擎。它建立在 TagMemo V9 已验证的降噪传播底座之上，首次将查询源形成、拓扑传递、河网生成、候选创新与最终排序放入同一个可计算闭环。Topology V3 的全部重计算已下沉至 Rust 原生内核（rayon 并行），JS 门面只负责 V9 查询观测、双场准备和结果组装。

**2026-08-04 升级**：新增"查询河网形态统计"环节 —— 在候选拓扑匹配之前，先估计查询侧感应河网在 Atomic/Propositional/Narrative 三种形态中的连续位置，并以三评分头连续混合方式计算候选图分。

## 工作机制
1. **JS 门面** (`RiverMemoEngine.js`):
   - class `RiverMemoEngine(v10Engine, options)` — 要求传入 TagMemoV10Engine 运行时
   - `getLegacyNativeTopologyV3()` — 延迟加载 rust-vexus-lite 的 `rerankRivermemoTopologyV3` N-API 函数
   - 原生不可用时抛出 `RIVERMEMO_NATIVE_TOPOLOGY_V3_UNAVAILABLE` 错误，不静默回退
   - `rerank()` 方法（行425）只准备连续查询场并消费原生结果
   - `rebindDatabase(db)` / `getArtifactSnapshot(options)` 委托给 v10Engine

2. **Rust 原生内核** (`rivermemo_topology_v3.rs`, 2813行):
   - 使用 rayon 并行计算、rusqlite 数据库、flate2 Gzip 解压
   - 关键结构: `NativeArtifact`, `MemoRuntime`, `MemoQueryObservation`
   - N-API 入口: `rerank_rivermemo_topology_v3()`（行2777）
   - 内部入口: `run_native()`（行2347）
   - **新增**: `compute_query_morphology()`（行1784）— 查询河网形态统计器
   - 边权重计算: `edge_weight()`, `independent_fraction()`

3. **2026-08-04 新增流水线环节**:
   ```
   → Rust/Rayon：六路候选超集
   → Rust：查询河网形态统计、稳定Softmax与低样本先验收缩  ← 新增
   → Rust/Rayon：双尺度路径几何
   → Rust/Rayon：查询河网—候选曲线相对拓扑匹配
   → ...
   ```

4. **总方程**:
   S_i = Π[0,1][S_i^field + Ω_Q^γ · Π[0,C_ri](λ_ri · C_i · [G_i - E(G|Z_i) - z·σ(G|Z_i)]+) + C_A · SmoothStep((A_i·R_i^A - τ_A)/(s_A - τ_A))]
   - 双场语义基线 + 关系拓扑创新 + 直接锚点创新
   - 关系拓扑通道只奖励候选超出同条件期望及其不确定性上界的正创新
   - 直接锚点通道保护 hop-0 事实接触
   - 两条创新通道均受独立上限约束，结果投影至 [0,1]
   - **G_i 现在由查询河网的形态概率连续混合节点图与边图读出**

## 查询河网形态Softmax（2026-08-04新增）
- 形态统计器不读取查询文本，也不读取候选，因此不依赖任何自然语言关键词，不会被召回候选池反向污染
- 生产实现: `compute_query_morphology()` (rust 行1784)
- 输出: M(R_q) = (p_A, p_P, p_N)，p_A+p_P+p_N=1
  - p_A (Atomic): 偏好浅层、聚集、能量集中且纵向延伸较弱的河网
  - p_P (Propositional): 偏好中等深度、同层关系、分叉与汇合
  - p_N (Narrative): 偏好深层、链式、方向一致且跨层持续的河网
- 稳定Softmax: 减去最大logit，温度T=1
- 低样本收缩: 置信度 c_M ∈ [0,1] 向均匀先验收缩，空河网不会被强行硬判
- 三评分头: G_i = p_A·G_i^atomic + p_P·G_i^prop + p_N·G_i^narr（节点图/边图连续混合）
- 结果 `queryMode` 保留为兼容诊断字段 = argmax(p_A,p_P,p_N)
