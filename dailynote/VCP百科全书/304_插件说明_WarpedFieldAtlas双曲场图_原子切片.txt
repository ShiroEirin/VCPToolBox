## 一、模块身份

`feature.json` 实测字段：

```text
manifestVersion 1.0.0 / name WarpedFieldAtlas / displayName 双曲场图 / version 0.1.0
pluginType feature / main index.js / renderer modules/warpedFieldAtlas/renderer/index.js
tests [tests/warped-field-atlas.test.mjs] / defaultEnabled true
```

自述定位：把知识库里 RiverMemo V5 的双曲场画出来；全景图看每个 Tag、每个日记片段落在哪一圈，查询视图看一条查询最近的是谁、半径改变了哪些名次。数据由后端插件提供，**只读**，在右栏「应用」里打开。

## 二、两个视图的坐标语义

| 视图 | 横轴 | 纵轴 | 说明 |
| --- | --- | --- | --- |
| 全景 panorama | 沿圆周按近邻排布的**角度** | 训练快照里的**实际半径** | 角度差不代表距离 |
| 查询 query | 与查询方向的**夹角** | 节点**半径** | 同一条虚线上的点到查询等距 |

代码内说明常量原文：`半径取自训练快照；沿圆周按近邻排布，角度差不代表距离。` / `横轴是与查询方向的夹角，纵轴是节点半径；同一条虚线上的点到查询等距。`

## 三、交互与常量

- 交互：滚轮缩放、拖动平移、点选节点；说明与详情在右侧栏，**不做悬停提示**。
- `FOCUS_SHARE = 0.7`：展开的话题团占整圈比例；`MOTION_MS = 220`：展开/收起动画时长；`MINI = 172`：缩略图边长；`NEAR = 10`：指针命中像素半径。
- 节点标志位：`FLAG_ENTRY = 1` / `FLAG_DIRECTION = 2` / `FLAG_SHELL = 4`。
- 场类型：`tag` 与 `chunk`；画面题签 `PLATE I/II/III` 分别对应 Tag 场、Chunk 场、查询。
- `focusMap(group, count)` 导出：把某一团拉宽到占整圈的 0.7，其余按同比例压窄，正上方接缝不动，环上先后次序不变。

## 四、前后端分工

后端插件只提供只读数据；前端 `mountAtlas(container, source)` 挂载界面，`source.get(route)` 取数据——Chat 内经主进程转到后端插件，命令行预览时直接请求本机服务。
