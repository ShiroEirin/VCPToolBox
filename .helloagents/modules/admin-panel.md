# admin-panel

## 职责

描述 `AdminPanel/` 内嵌管理前端及其与后端路由的配合关系。它不是独立前端仓库，而是项目的一部分静态资源与页面集合。

## 关键文件

- `AdminPanel/script.js`：前端主逻辑、登录、状态拉取与操作触发。
- `routes/adminPanelRoutes.js`：管理接口与静态资源协作入口。
- `server.js`：管理面板挂载、鉴权和页面交付装配点。

## 接口定义

| 接口 | 方向 | 说明 |
|------|------|------|
| 管理页面静态资源 | server -> browser | 交付管理面板 HTML、脚本与资源 |
| 管理路由 | browser -> routes/adminPanelRoutes.js | 读取配置、系统状态和执行管理动作 |

## 行为规范

### 页面交付
**条件**: 用户访问管理面板。  
**行为**: 后端提供静态资源，页面再调用管理路由获取状态和执行操作。  
**结果**: 展示系统配置、运行状态和管理入口。

### 集成约束
**条件**: 修改管理面板相关功能。  
**行为**: 同步检查 `AdminPanel/` 静态页面与 `routes/adminPanelRoutes.js` 的接口契约。  
**结果**: 避免前后端协议脱节。

### 鉴权与挂载
**条件**: 启用管理面板或访问敏感管理接口。  
**行为**: 经过 `server.js` 的挂载与鉴权逻辑后，再进入具体管理页面和路由。  
**结果**: 管理界面与后台控制入口保持一致的安全边界。

## 依赖关系

